# 鬼化祢豆子待机动画 v2：稳定膝盖和小腿

以已认可的 v1 为基础，仅修正用户指出的膝盖和小腿随呼吸忽大忽小的问题。静态原画、12 帧、10 FPS、1.2 秒周期、游戏尺寸标定与 v1 相同。

根因是网格形变中的衣摆控制点也会牵拉邻近腿部；单纯缩小膝盖控制点振幅不能完全消除腿部粗细变化。本版使用两块沿腿部轮廓设置的局部遮罩，让膝盖和小腿保持水平宽度，仅保留最大 0.16 个高清像素的纵向呼吸位移，并向大腿平滑过渡。脚底仍完全固定。遮罩以外的动画像素逐帧与 v1 相同，保留已认可的上身、头部、双手、头发和远离腿部的衣摆运动。

- `review/idle-preview.webp`：无损动画预览。
- `review/idle-preview.mp4`：4.8 秒、4 个循环的视频。
- `review/lower-leg-comparison.webp`：膝盖和小腿修改前后对照。
- `frames/`：12 张 1120×1664 高清透明帧。
- `game-frames/`：12 张 1024×640 游戏画布透明帧。
- `idle-atlas.png`、`idle-atlas.json`：独立待机图集和帧坐标。
- `lower-leg-stability-mask.png`：本次局部修正区域。
- `animation.json`：循环、脚底、头部、腿部形变及其他区域不变的检查记录。
- `nezuko-awakened-idle-v2-refined.zip`：更新后的透明帧、图集和参数交付包，以此包为准。

检查结果：抽查 8 处小腿和绑腿截面，其中 7 处在 12 帧中宽度完全不变；余下 1 处仅有抗锯齿边缘引起的 1 个高清像素差异。腿部稳定核心区域的横向形变为零。循环衔接、脚底固定及修正区域之外逐帧不变的检查均通过。
