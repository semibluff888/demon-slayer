# 鬼灭之刃 · 月下对决

Godot 4.7.1 / GDScript 制作的2D手绘动漫格斗游戏。支持炭治郎、善逸、本地双人、电脑对战及自由练习，允许同角色对战。战斗采用60Hz固定逻辑，渲染帧率不影响搓招或招式时序。

第二阶段「专属战斗动作与打击反馈」已接入：两名角色的体术、翻滚、前投／受投／拆投，以及回旋必杀和四种奥义均使用专属逐帧动作。完整结果见 [阶段验收](docs/phase2-acceptance.md)，制作过程见 [实施记录](docs/phase2-progress.md)。

人物尺寸校准：已检查两人的全部78组动作，修正17组体术、斩击、MAX、翻滚、投技和受击动作的比例。调整明细、对照图与离线复现见 [人物尺寸一致性修正](docs/character-scale-review.md)。

## 比赛视觉升级（battle-v5）

最新验收入口为 [本地预览](artifacts/battle-v5/index.html)，包含实际引擎截图、四种超杀录像和性能记录。21 块原生 1536×1024 局部重绘合成为 9600×2400 连续全景，运行时使用四块带采样边缘的纹理，保持镜头、地面和人物比例。支持 960×540 至 3840×2160，非 16:9 留边。

战斗头像采用新绘高清头肩像；血条、回合标记和计时统一金边水墨样式，呼吸槽位于下方两侧。练习信息位于底部中央，F3 设置中的「展开输入指导与搓招提示」可切换详细说明。水流、雷光、火焰分开绘制实体纹理与辉光；超杀／MAX 在原有 12／18 帧停顿内显示暗场、能量球、完整技能名，MAX 加入面部特写。四种标题统一 36px；暂停、重置和招式中断均正确冻结或清理演出。

来源、实际尺寸与未知费用记录在 output/imagegen/battle-v5/。安装 requirements-art.txt 后，离线重建使用项目虚拟环境执行 tools/build_battle_art.py --part all，不调用生图服务。本轮不改变判定、伤害、耗气、位移、取消窗口或招式帧数。

## 启动

Windows双击 **launch.cmd**，或在Godot中导入 project.godot 后按F5。本机引擎：

```powershell
& 'D:\Godot_v4.7.1-stable_win64.exe\Godot_v4.7.1-stable_win64.exe' --path 'J:\Project\demon-slayer'
```

默认1280×720，支持960×540至3840×2160连续缩放，非16:9留边。人物比例固定，镜头只横向卷动；版边增加少量画面留白，完整显示横卧受投姿态。选人页可以分配两组键盘或手柄；双人要求不同设备，断开手柄自动暂停。

## 操作

A/B/C/D是**逻辑攻击键**，不是键盘字母或Xbox的按钮名称。

| 动作 | 键盘1 | 键盘2 | Xbox手柄 |
| --- | --- | --- | --- |
| 移动、蹲下、跳跃 | WASD | 方向键 | 十字键 / 左摇杆 |
| A 轻斩 | F | J | X |
| B 轻体术 | G | K | A |
| C 重斩 | V | N | Y |
| D 重体术 | B | M | B |
| 暂停 | Esc | Esc | Start |

键盘攻击键按两排排列：P1为FG / VB，P2为JK / NM。键位按物理位置识别。F1显示判定框，**F2静音**，练习中F3打开设置，Backspace重置位置与气槽。暂停菜单可以查看基础攻防、全部普通技、必杀与奥义。

- **方向记法**：朝右时，2为下、3为右下、6为右、4为左、5为不按方向、j.为空中；朝左时水平镜像。236即↓↘→，623即→↓↘，214即↓↙←。
- **普通技**：ABCD均有站立、蹲下和空中版本。A/B适合起手，C强调距离和伤害，D侧重近身；2D扫倒且不能取消。体术使用独立站立／蹲下／空中轻重动作，保留刀剑架势和近身定位。
- **防御**：后方向站防、后下方向蹲防。空中攻击必须站防，下段必须蹲防，其余打击两种防御均可；空中不能防御。
- **冲刺**：12帧内双击同一水平方向，中间需要松开。前冲16帧、后冲14帧，可接攻击、跳跃；无无敌或自动防御。
- **方向投**：双方地面近身时6+D前投、4+D背投，远处出重体术。单按D与连段取消不自动转投。抓取后7帧内按D拆投；同帧双投互拆，同帧打击打断抓取。起身有8帧投无敌。
- **翻滚**：A+B前滚、4+A+B后滚，共28帧。第3—18帧躲避打击与飞道具，能穿过对手；全程可被投，动作中不能攻击或取消，最后8帧有明确收招。
- **输入容错**：236/214为30帧（0.5秒），最后横方向后可在12帧（0.2秒）内按攻击；允许省略斜方向、短暂回中及久蹲后接招。攻击可比最后方向提前2帧，复用组合键等待，不增加普通攻击延迟。623仍为20帧、双236仍为36帧，两者末方向到攻击仍为6帧。动作执行缓冲6帧，组合键容差2帧；长按不重复，命中停顿和超杀停顿期间仍接受输入。

键盘1可用“两拍”完成下面两招，`A/C`、`B/D`各选一个攻击键；先松开S，再按横方向，攻击不必同一时刻按下。

| 招式 | 面朝右 | 面朝左 |
| --- | --- | --- |
| 236+A/C | S → 松S，D＋F或V | S → 松S，A＋F或V |
| 214+B/D | S → 松S，A＋G或B | S → 松S，D＋G或B |

只停在S＋D或S＋A的斜下方向不会触发这两招。搓招计时从离开起始下方向算到攻击；中途或最终方向按住不刷新窗口，已识别的方向序列不会被下一次攻击重复使用。

## 角色必杀与奥义

普通必杀不消耗气槽。A/C释放斩击轻重版，B/D释放回身/回旋轻重版；重版增加射程或伤害并增加破绽。

| 指令 | 灶门炭治郎 | 我妻善逸 |
| --- | --- | --- |
| 236+A/C | 水之呼吸·壹之型 水面斩：短程水刃飞道具 | 雷之呼吸·壹之型 霹雳一闪：直线突进 |
| 623+A/C | 水之呼吸·贰之型 水车：上升对空 | 居合·上撩：快速对空 |
| 214+B/D | 水之呼吸·陆之型 扭转漩涡：回旋多段 | 居合·回身斩：短撤步接回斩 |
| 236236+A/C | 水之呼吸·拾之型·生生流转：多段超杀 | 雷之呼吸·壹之型·霹雳一闪·六连：六段突进 |
| 236236+A+C | 日之呼吸·火之神神乐·碧罗之天：MAX超杀 | 雷之呼吸·壹之型·霹雳一闪·神速：MAX超杀 |

善逸的“上撩”“回身斩”属于游戏演绎动作，不属于其他雷之呼吸型。炭治郎偏控距和衔接，善逸移动更快、突进更强；不强行让两人都有飞道具。水刃是游戏化表现，每人最多同时存在一枚；离手后即使施放者受击仍继续飞行，碰撞、防御、命中或超时后消失。

## 连段与呼吸槽

基本路线：**跳入 → 地面轻技最多两招 → 重技 → 必杀 → 超杀或MAX**，可以省略中间环节。普通技命中或被防可取消，必杀接超杀只允许命中确认；空挥不能取消，同一地面普通技不能在一条连段中重复使用。首版只支持有限浮空追加，初次空中命中后最多追加两次招式；多段超杀按一次追击，倒地不能追加。

| 用途 | 已验证路线 | 炭治郎伤害 | 善逸伤害 |
| --- | --- | --- | --- |
| 下段确认 | 2B → 2A → 5C → 236A | 200 | 200 |
| 跳入 | j.C → 落地5A → 5C → 214B | 249 | 244 |
| 1格收尾 | 5A → 5C → 236A → 236236A | 397 | 396 |
| MAX收尾 | 5C → 214D → 236236AC | 491 | 489 |

数值基于1000生命，左右朝向与版边均验证。取消回旋技时可以在第一段命中后接超杀，未打出的后续段不计伤害。跳入路线在下落过程中出j.C，落地后接轻斩。练习“首击后防”可识别衔接中的空隙。

伤害按招递减：100%、90%、80%、70%、60%、50%，之后最低40%；超杀最低50%。同一招内部多段共享倍率，HUD连击数按命中次数累计。对手恢复行动后连段即结束，显示文字延时不影响逻辑。

呼吸槽上限300点，100点为1格：

- 1格超杀消耗100，MAX消耗300；只在成功启动时扣除一次。气量不足不给予普通技或低级超杀替代。
- 普通技和必杀命中，攻击方获得实际伤害的25%；受击方获得15%，整数取整。超杀攻击方不回气，空挥不涨气。
- 防御每个攻击实例获得3点，多段不会逐段刷防御收益。必杀与超杀有削血，削血不能KO。
- 新比赛从0开始，局间保留双方气量；平局重赛恢复该局开场气量。

## 自由练习

主菜单选择“自由练习”，选角色后立即开始，没有回合倒计时或胜负结算。默认3格气。

- 木桩：站立不防、站立防御、蹲下防御、首击后防。
- 呼吸槽：0格、1格、3格、无限气；选择有限档位设置当前值，之后按正常战斗涨气和耗气。
- 输入记录显示方向与ABCD，HUD显示已识别招式、连击数及实际总伤害。右侧按当前设备与朝向显示236/214的实际按键；斜下未松、方向超时、攻击偏晚和攻击键类别错误会显示搓招提示。
- 连段结束回到空闲后自动补血；Backspace重置双方位置、生命、气槽和输入记录。
- F3或暂停菜单打开设置，手柄也可通过Start和原生菜单控件操作。

## 规则与实现

普通对战1000生命、60秒一局，先赢两局获胜。超时按剩余生命判胜，同时倒地或同血超时重赛该局。投技联动完成后再结算超时或致命伤害。AI使用12帧前的可观察对手状态，通过同样的方向与按钮输入完成搓招、取消和耗气。

`Combat.step([p1, p2])` 的指令格式：

```gdscript
{"x": 0, "y": 0, "buttons": 0}
# x: 世界方向 -1左 / 0 / 1右；y: -1上 / 0 / 1下
# buttons: 持有位掩码 A=1, B=2, C=4, D=8，例如 A+B=3
```

输入适配层只负责采样，按下边沿、搓招、双击、组合键由纯逻辑识别器统一处理。旧的light/heavy/skill/throw指令已迁移。所有运行状态进入确定性快照，渲染与音效不改变战斗。

- `resources/characters/*.tres`：角色定义，包含移动参数、12个普通技、8个必杀/奥义映射、投技、角色说明与招式表。
- `moves/core/*.tres`：42份运行时招式资源，配置帧数、分段伤害、取消类别、资源消耗、飞道具、动画与特效映射。
- `scripts/combat_catalog.gd`：扫描、注册角色及招式；新增角色不需要在战斗、AI或选人页添加ID分支。
- `scripts/combat.gd`、`fighter_state.gd`、`command_recognizer.gd`：纯逻辑战斗、角色状态及固定帧输入。
- `scripts/practice_controller.gd`：练习木桩、资源设置与恢复。
- `scripts/presentation/`：角色表现、独立飞道具、固定倍率镜头和HUD。动画名与招式ID分离，按逻辑阶段及实际多段命中同步动作。
- `tools/build_combat_data.py`：显式重建本版资源的工具；修改资源后不要运行该工具，除非也同步了生成参数。运行游戏不进行代码或资源生成。
- `docs/combat-system.md`：战斗、表现资源与阶段验收约定。

本阶段新增28张版本化动作源图，运行图集合计78组动作、617张不同画帧（炭治郎306、善逸311）。前后翻滚、投技联动和拆投由 `CharacterDefinition.state_animations` 选择；每招通过 `MoveData.presentation` 引用 `resources/presentation/` 的特效轮廓、声音和残影配置。没有调整启动／有效／收招帧数、位移、伤害、资源消耗或取消规则。EX技、MAX爆气模式、防御取消、长空连、联网和新增角色另立阶段。



## 本阶段快速体验

进入「自由练习」→选择炭治郎或善逸，默认3格气。P1用WASD移动，G／B分别为轻／重体术；配合S或跳跃比较站、蹲、空中版本。F+G前滚，后方向+F+G后滚；近身前／后方向+B体验前投／背投，另一方在抓取后按逻辑D拆投。

面朝右时，水／雷必杀为236+F/V、623+F/V、214+G/B；1格奥义为236236+F/V，MAX为236236+F+V。朝左镜像。F3切换木桩防御和气量，Backspace重置，F1查看判定框，F2静音。

命中有短促火花和停顿，防御显示弧形格挡，空挥只有出手声；拆投显示双方推开与独立音效，耗气显示扣除格数，气不足显示红色槽框和提示音。六连的六次出手分别对应六个逻辑命中段，中间段降低音量、火花与震屏强度。
