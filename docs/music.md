# 背景音乐（BGM）

游戏的 BGM 分三类场景：主界面、选人（含选图）和战斗；结算界面沿用战斗曲。曲目、入场点、循环区间、混音音量和淡化时长都写在 `resources/music/library.json`，`scripts/music/director.gd`（`MusicDirector`）每帧读取界面、暂停、必杀动画和回合状态来决定播放什么、多大声。音乐只读游戏状态，不影响战斗模型；30/60/144 FPS 确定性测试照常有效。

## 文件

| 位置 | 内容 |
| --- | --- |
| `output/music/source/<标识>.m4a` | 8 首源音频：官方 AAC 原始音轨，或从 B 站完整音轨无损截取的片段。不打包 |
| `output/music/sources.json` | 每首的官方曲名、作者、专辑、来源链接、截取区间和 SHA-256 |
| `output/music/build-report.json` | 最近一次构建的源/成品响度、真峰值、增益、时长和大小 |
| `art/music/<标识>.ogg` | 游戏用 Vorbis（q5），统一到 −16 LUFS；`.import` 必须保持 `loop=false`，循环由导演按 cue 点处理 |
| `resources/music/library.json` | 运行时清单：显示名、文件、时长、cue 点、场景候选与默认、`mix` 段 |
| `scripts/audio_buses.gd` | 在代码里建 Music / SFX / Voice 三条总线（Master 下），Music 总线带一个暂停时启用的低通滤波，Master 带一个硬限幅器 |
| `scripts/music/library.gd` | 读取清单、校验选项、解析「随机」和「延续主界面音乐」 |
| `scripts/music/director.gd` | 播放器池、交叉淡化、循环、高潮跳段、压低、试听和预加载 |

## 场景规则

| 场景 | 曲目 | 进入 |
| --- | --- | --- |
| 主界面 | 默认「炎 · 电影版」，可选另外三首或随机（每次启动抽一首） | 启动淡入 1.0 s。离开时记住位置，回来接着放 |
| 选人、选图 | 默认「柱结集 · 无限城之邀」从 2:52 起；可改为「延续主界面音乐」 | 与主界面曲 1.2 s 等功率交叉淡化；选人和选图之间不换曲；从对战或结算回来时重新从 2:52 进入，刚才的战斗曲也是这首时同样如此 |
| 战斗 | 默认随机（不与上一场相同），可固定一首 | 确认场地后选人曲 0.8 s 淡出、战斗曲 1.0 s 淡入；若与选人曲是同一首则直接接着放。「再来一场」和暂停里的「重新开始比赛」都会重新抽曲并从入场点起播 |
| 结算 | 沿用战斗曲 | 决胜 KO 时 1.5 s 内降到结算音量，一直保持到离开结算界面 |

对战中：

- **回合之间**：不重开，连续播放。
- **KO / 时间到**：压低 5 dB（0.15 s），下一回合开场 1.0 s 内恢复。
- **最终回合**：双方各赢一局后的开场，用 1.5 s 交叉淡化跳到 `climax`；平局重赛不会再跳一次。
- **必杀 / MAX 动画**：压低 14 dB（0.2 s），结束后 1.0 s 恢复；动画自带的音轨走 SFX 总线。
- **暂停**：压低 3 dB，同时打开 Music 总线的轻度低通（约 2.5 kHz），音乐仍清晰可闻。暂停菜单、帮助与招式表、木桩与气槽设置、游戏设置共用这一状态；只有在设置里试听其他曲目时才完全打开。
- **练习模式**：同一套战斗曲，无限循环；重置练习不影响音乐。

快速来回切换界面时，正在淡出的同一首曲会被直接“拉回来”，不会叠出第二份。播放器池共 3 个，足够同时覆盖循环接缝和场景交叉淡化。

主界面时后台预加载选人曲；进入选人时就抽好本场战斗曲并预加载。

## cue 点

每首曲目按用到它的场景各写一组 cue（秒）：

- `start`：入场点。
- `loop_start` / `loop_end`：循环区间。播放到 `loop_end − crossfade` 时，新的播放器从 `loop_start` 起播，两者等功率交叉淡化；`crossfade` 缺省取 `mix.fades.loop`（2.0 s）。
- `climax`：最终回合的跳转点，只用于战斗。

| 鬼杀队 | 主界面 | 0:00 | 0:00 → 3:20.2（接缝 3 s） | — |
| 狛治 · 欢迎回家 | 主界面 | 0:00 | 0:00 → 1:47.4（接缝 3 s） | — |
| 柱结集 · 无限城之邀 | 选人 | 2:52 | 2:51.1 → 5:36.4 | — |

## 音量

**统一响度。** 所有成品都统一到 −16 LUFS、真峰值 ≤ −1.5 dBTP，只做整体增益，不压缩动态。原始音源为 −8 至 −10.7 LUFS，真峰值超过 0 dBTP。

**总线。** Master 承载主音量和静音（F2），并用硬限幅器（上限 −0.5 dB）防止音乐和密集命中叠加时削波。Master 下面有三条总线：

| 总线 | 内容 | 默认 |
| --- | --- | --- |
| Music | BGM | 70% |
| SFX | 合成音效、必杀动画音轨和视频声音 | 100% |
| Voice | 预留给人物语音 | 尚无设置项 |

**场景基准。** 在 `mix.levels_db` 里，相对 −16 LUFS 的文件：

| 场景 | 偏移 | 默认设置下的实际响度 |
| --- | --- | --- |
| 主界面 | +1 dB | 约 −18 LUFS（音乐 100% 时约 −15） |
| 选人 | −1 dB | 约 −20 LUFS |
| 战斗 | −7 dB | 约 −26 LUFS |
| 结算 | −12 dB | 约 −31 LUFS |

战斗中音乐退到后景，给命中音效和以后的人物语音留出空间。合成音效（`audio.gd` 的 `CUE_DB`）随之从 −17 dB 提到 −5 dB：一串命中加挥空的瞬时响度最大约 −21 LUFS，比战斗音乐高约 5 LU。必杀动画音轨约为 −15 LUFS，放映时音乐再压低 14 dB。

2026-10-19 试玩反馈音乐偏小（音乐滑块已在 100%），各场景基准整体提高了 4–5 dB，音效同步提高 4 dB 以保持层次。

压低量在 `mix.duck_db`，淡化时长在 `mix.fades`，单曲微调用曲目的 `gain_db`。

## 设置

「游戏设置」分两个分页：

- **声音与演出**：静音、主音量 / 音乐 / 音效滑块、主界面 / 选人 / 战斗三个选曲下拉框，以及必杀动画演出开关。在下拉框里切换曲目会立即试听；关闭设置后回到当前场景应放的曲目，被试听打断的对战曲从原位置接上。
- **按键设置**：两名玩家的控制方式和键位。手柄断开时打开设置会直接进入这一页。

设置保存在 `user://settings.cfg`：
- `[audio]`：`volume`、`music_volume`、`sfx_volume`、`muted`
- `[music]`：`title`、`select`、`battle`

清单里不存在或不属于该场景的曲目会回退到默认。

## 新增或调整曲目

1. 把源音频放到 `output/music/source/<标识>.m4a`，在 `sources.json` 里登记来源和 SHA-256。
2. 在 `library.json` 的 `tracks` 里加一项（显示名、文件、按场景的 cue），并加入对应场景的 `choices`。
3. 构建并导入：

   ```powershell
   .venv\Scripts\python.exe -X utf8 tools/build_music.py --only <标识>
   & $godot --headless --path . --import
   ```

4. 挑 cue 点：
   - `--profile <标识>`：每 2 s 的响度曲线。
   - `--suggest-loops <标识> [--scene battle]`：在 `library.json` 当前循环点 ±6 s 内，按交叉淡化窗口的色度、节奏和响度相似度给出前 5 个接缝，并给出高潮点附近 1 s 内响度上升最大的位置。
   - `--preview <标识> [--scene battle]`：把循环接缝和高潮跳段渲染成 `artifacts/music/*.wav` 试听。
5. 曲名有新字时重新运行 `.venv\Scripts\python.exe -X utf8 tools/subset_fonts.py`。字体子集会扫描 `resources/` 下的 JSON。

## 测试

- `tests/music_tests.gd`：
  - 清单完整性（文件、时长、cue 范围）。
  - 设置的读写与回退。
  - 用虚拟时钟驱动的全部场景规则：交叉淡化、记位续播、随机不重复、循环接缝、暂停闷音、必杀压低、KO、最终回合跳段、结算、练习、试听、总线路由和 F2 静音。
- `tests/music_pipeline_tests.py`：源文件校验和、清单一致、`.import` 不循环、构建报告满足响度目标。

在测试和截图工具这类脚本化的 SceneTree 下，导演默认关闭（`enabled = false`），现有测试和截图不受音乐影响；`music_tests` 会显式开启。
