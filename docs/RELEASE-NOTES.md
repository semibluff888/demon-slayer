# v0.1.1 — Windows 便携版

下载 `DemonSlayer-<版本>-windows-x86_64.zip`，完整解压后双击 `DemonSlayer.exe`。
无需安装 Godot 或 Python，请保留同目录的 `DemonSlayer.pck`。

- 胜方续局保留余血，并按剩余时间恢复 100～200 点，最高 1000；败方满血，平局恢复该局开场血量。
- 下一局开场直接显示继承后的血量，不再出现从满血下降的假扣血效果；实际受伤仍保留血条动画。
- 默认 ABCD：P1 为 U / I / J / K，P2 为小键盘 5 / 6 / 2 / 3。整套旧默认配置自动迁移，自定义配置保留。
- 开发源码的 launch.cmd 使用无控制台 Godot，启动后不再保留命令窗口。
- 炭治郎、善逸、祢豆子、猗窝座，四张对战地图。
- 电脑对战、本地双人、自由练习，支持键盘与手柄。
- 内置帮助、改键、控制器分配、音量设置。
- 包内附中文操作说明、第三方许可；另附 SHA-256 校验文件。

适用于 Windows 10/11 x64、OpenGL 3.3 显卡。发行版未代码签名。
GitHub 自动提供的 Source code 压缩包是源码，需要 Godot 才能运行；玩家应下载上面的 Windows ZIP。
