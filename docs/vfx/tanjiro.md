# 炭治郎技能特效

目标：复刻《火之神血风谭》中炭治郎的水之呼吸和火之神神乐特效。参考拆解见 [tanjiro-reference.md](tanjiro-reference.md)。已重做水面斩、水车、扭转漩涡、生生流转、碧罗之天和六个刀斩普通技（5A/5C、2A/2C、jA/jC），每招都有普通形态和觉醒水火交融两版（碧罗之天两版都是纯火）。体术普通技（B/D）和投技仍走原有特效。

## 结构

| 文件 | 作用 |
|---|---|
| `scripts/presentation/vfx/tanjiro_vfx.gd` | 核心，挂在 `EffectsView` 下：图层、粒子池、命中爆发、共用的笔触绘制；`MOVES` 把招式分派给各招式脚本，其余招式和其他角色仍走原代码 |
| `scripts/presentation/vfx/tanjiro/technique.gd` | 招式脚本的基类：`emit`（每个战斗 tick 生成粒子）、`draw`（按招式帧画形状）、`contact`（命中）、锚点（判定结束后形状留在原地）、超杀蓄力时钟 |
| `scripts/presentation/vfx/tanjiro/water_slash.gd` 等 | 每招一个脚本：`water_slash`、`water_wheel`、`water_vortex`、`water_dragon`、`sun_halo`、`blade_trail` |
| `scripts/presentation/vfx/tanjiro/paths.gd` | 笔触沿着走的中心线：`Arc`（弧/椭圆环）、`Helix`（螺旋，分前后半）、`Wave`（龙身波形）、`Sweep`（普通技刀路） |
| `scripts/presentation/vfx/tanjiro/kit.gd` | 共用常量：图层、精灵表格子、水丝束、交融火丝和附着火片的排布、配色 |
| `scripts/presentation/vfx/vfx_ribbon.gd` | 三角带彩带（直接提交三角形，弧线自交也安全），支持按弧长平铺纹理、选取纹理行 |
| `scripts/presentation/vfx/vfx_pool.gd` | 确定性粒子池（精灵表、重力、阻力、拉伸），只按传入的演出时间推进 |
| `scripts/presentation/vfx/blade_track.gd` | 读取刀身轨迹 `blade-tracks.json` |
| `scripts/presentation/vfx/shaders/erode_*.gdshader` | 彩带侵蚀：顶点 alpha 表示"存在度"，配合噪声碎成泡沫或火舌（`erode_mix` 正常混合，`erode_add` 叠加） |
| `art/effects/tanjiro/` | 生图素材加工结果和 `manifest.json`（来源、提示词、哈希） |

图层顺序（同一 z 时按树序）：

| 图层 | z | 内容 |
|---|---|---|
| BACK | 1 | 缠绕形状的远侧半圈（扭转漩涡、生生流转蓄力），压在两名角色身后（侵蚀 Shader） |
| WATER | 9 | 水丝彩带、觉醒时的火丝和附着火片、螺旋近侧半圈（侵蚀 Shader） |
| SOLID | 9 | 月牙浪精灵、卷浪、龙头、碧罗之天的火环和火舌 |
| FRONT | 10 | 命中水花、水珠、泡沫、火粒、月牙浪的火芯 |
| FLAME | 10 | 刀光残影（叠加） |
| LIGHT | 10 | 辉光、水雾、X 字闪光、冲击环、火焰闪光、发动闪光、镜头光芒（叠加） |

角色在 z 2，`EffectsView` 在 z 10；WATER 和 SOLID 低一层，受击者会被抬到 z 10，因此始终压在水体之上。

## 规则

- **形状由招式帧驱动**：形状只由 `move_frame` 和刀身轨迹决定。非冻结时可叠加物理插值小数，截图和测试会关闭这一项。
- **粒子由战斗 tick 驱动**：粒子按战斗 tick 生成，每个 tick 只生成一次，随机数由攻击实例和 tick 决定，因此逐帧推进和批量推进的结果相同。
- **冻结**：粒子和爆发只随 `EffectsView` 的演出时间推进，命中停顿、超杀冻结、暂停、KO 冻结时全部静止。唯一的例外是超杀蓄力：形状按 `charge_age`（超杀冻结已过的帧数加招式帧）变化，所以冻结期间蓄力仍在转动、收紧，但粒子不动。
- **超杀发动**：生生流转和碧罗之天自己画蓄力，`SuperView` 对它们只保留压暗、切入和标题，不再画通用的能量球（`EffectsView.draws_charge`）。
- **留在原地**：水车和碧罗之天在判定结束时记下锚点，之后形状停在画出的位置继续侵蚀，不再跟随角色。
- **通用命中特效**：已重做招式的通用命中记录仍照常写入（测试依赖），但白光减弱、星芒不画，由本模块的金色 X 字和水花代替。
- **配色**：觉醒时水和火都用正常混合穿插；叠加混合的橙光会把蓝水冲成发白的淡紫。交融版的火用深红主体加黄色裂纹（`hybrid-fire-strands`、`hybrid-fire-chips`），贴近参考游郭篇；纯火之神神乐（碧罗之天）用黄白芯的 `fire-strands`、`fire-petals`，冷却后转成深红。

## 招式

### 水面斩（236A/C）

| 阶段 | 表现 |
|---|---|
| 起手（第 3 帧起） | 刀身上出现细水带，水珠被吸向刀身；判定前 4 帧身体蓝白闪光 |
| 判定 | 自脑后经头顶劈至前下方的大弧水斩，由 4 股收尖水丝和尾部 3 根散丝组成，外缘有浮世绘卷浪，最外侧是淡白刀光；1.5 帧内扫出，第 3 帧起从尾部侵蚀并碎成水珠；脚下有亮青色水痕 |
| 弹道 | 竖立的月牙浪（轻版、重版各一张图），后拖水丝，地面有水痕，沿途掉落水珠和水雾；寿命结束时碎成水珠和泡沫 |
| 命中 | 第一帧即为完整大小的水花冠，加金色 X 字闪光、冲击环、放射水珠；防御时是小水花向后溅 |
| 觉醒 | 3 股火丝穿插在水丝之间，另有 3 股压在水面上，弧上附着 8 片撕裂状火片，火比水晚一点烧尽；月牙浪内包 3 道火芯；起手、侵蚀、弹道、命中和消散时都会甩出深红火片 |

重版（236C）的弧、浪、粒子均放大约 1.2 倍。

### 水车（623A/C）

刀尖画出的竖直水环，随后空翻：前缘从身前向上、越过头顶、经身后绕到脚下（与画面里刀的走向一致），外缘有卷浪，前缘甩出水珠和泡沫，前端有一点亮光。起跳时脚下溅起水花、地面有水痕。判定结束后水环留在画出的位置，从尾部侵蚀碎成水珠和水雾。觉醒时火丝和火片织入水环。重版约大 1.12 倍。

### 扭转漩涡（214B/D）

发动时身体周围炸开白色水花，随后一道白色干笔刷螺旋自地面卷起、绕身旋转，内侧还有一股更细的蓝色水螺旋。每圈的远侧半圈画在两名角色身后并略带蓝灰，近侧半圈压在身前，形成纵深。近侧沿旋转方向甩出水珠；结束时从下往上散开成长条白色水痕。觉醒时一股深红火螺旋缠在白色笔刷上。两段命中：第一段水花较小，第二段较大。

### 生生流转（超杀）

蓄力（超杀冻结和起手）：水丝螺旋绕身收紧、远侧在身后，脚下水纹向外扩散，身体蓝光逐渐增强，伴随横向镜头光芒。放出时水花和水环一闪，随后水龙从刀前涌出：龙身是一束水丝和卷浪，沿波形一路起伏，前端是生图的水龙头。四段命中时龙头各涌出一次水花；结束时从尾部散开，龙头淡出并炸成水花。觉醒时龙身织入火丝，龙鬃里带火片。

### 碧罗之天（MAX）

两种形态都是纯火。蓄力：两道细火环绕身旋转收紧，暖光增强；放出时身体金光一闪，配横向金色镜头光芒。后空翻画出三道同心倾斜火环（白黄芯、橙身、红缘，主环外缘生出火舌），前端甩出火粒。判定结束后火环留在原地，约 0.1 秒后开始褪成更细的深红色带，并从尾部碎成深红火片和余烬。命中是金色 X 字、火焰闪光、火环和四散火粒，没有水花。

### 刀斩普通技（5A/5C、2A/2C、jA/jC）

沿原有的刀路曲线（`EffectsView.CUT_CURVES`）画一段短水丝，外缘有一道亮白刀线，出刀时甩出水珠；重攻击更粗，带卷浪和金色 X 字命中，轻攻击只有水花和冲击环。觉醒时织入火丝（重攻击另有附着火片）。

## 工具

```
python tools/build_vfx_reference.py overview|burst|palette|board ...   # 参考视频抽帧、调色板、参考板
python tools/build_blade_tracks.py tanjiro                              # 刀身轨迹与 QA 接触表
python tools/build_tanjiro_vfx_art.py                                   # 生图素材 -> art/effects/tanjiro/
godot --path . --fixed-fps 60 --script res://tools/capture_tanjiro_vfx.gd -- --moves=236A,623C,214D,super,max,5C --every=1 [--hd]
python tools/build_tanjiro_vfx_review.py sheet|compare|video|montage <截图目录名> ...
```

生图走用户的 CPA 接口（gpt-image-2），调用时用 `-Python .venv\Scripts\python.exe`（项目 venv 里装了 `openai`）。提示词、原图和记录在 `output/imagegen/tanjiro-vfx-v1/`。CPA 有时直接返回带透明通道的 PNG，有时按提示词给纯色底；加工工具会优先使用真实 alpha，其次识别品红、绿幕（火焰用，深红描边保持不透明）和黑底。硬边赛璐璐的条带用 `'seam': 'cut'`（沿差异最小的路径拼接首尾），避免交叉淡化留下半透明重影。新增导入的贴图需要在 `.import` 中开启 `mipmaps/generate=true`。

## 测试

`tests/tanjiro_vfx_tests.gd`（已加入 `tests/run_tests.ps1`）覆盖以下内容：

- 路由与图层（含 BACK 层在角色身后）、超杀蓄力归属
- 刀身轨迹、水面斩弧线几何
- 每招、两种形态：绘制、粒子生成、火片只在觉醒时出现（碧罗之天两种形态都有火）
- 冻结与零速
- 不修改战斗状态
- 命中爆发（轻普通技没有 X 字）
- 弹道释放、留在原地的锚点
- 全部粒子在 1.5 秒内消失
- 重置清空
- 逐帧与批量推进结果一致
