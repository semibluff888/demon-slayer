## 视觉语言

| 元素 | 观察 | 本游戏的对应 |
|---|---|---|
| 爆血火焰 | 粉红到品红的火焰：白芯、品红主体、深红尾，边缘撕裂成碎片；鬼化后偏血红、更浓 | 烘焙贴图 `blaze-*`（命中爆）、`flame-strip`（火焰带）；普通粉红、鬼化深红 |
| 爪痕 | 三道一组的细长新月形爪痕，白芯、品红身、深红碎边剥落；地面拖出深红短爪痕 | `claw-strip` 贴图的三道爪痕（`claws`），重爪在地面留 `scratches` |
| 血屑 | 品红内芯、深红外缘的不规则碎片漂浮翻转 | `flakes.png` 粒子 |
| 起手血聚 | 粉红光球外绕一圈黑红尖刺墨（連続蹴り、爆血突き起手） | `activation`：粉白光球、黑红墨刺、身体泛粉 |
| 白色气浪 | 踢技周围的白色弧线、竖环；かかと落とし命中时白色漫画冲击星 | `crescent`、`ring`、`star.png` |
| 十字闪 | 命中时黄白色的两道交叉细光 | `cross` |
| 黑石与焦坑 | 砸地时黑色岩板翘起、碎石飞溅，焦坑中心留粉红余火 | `rubble`（借用猗窝座的 `rocks.png`）、`crater` |
| 火焰旋柱 | 爆炎裂き：贴地火线烧向目标，在目标处卷起粉红火焰旋风，中间一道黄白竖线 | `tornado` |
| 火焰穹顶 | 爆血かかと落とし：洋葱形的巨大火焰，火舌高低错落、白热电纹 | `dome` |
| 蓝光 | 原作的「长按」提示 | 不采用 |

## 时间规律

- 命中爆首帧就是最大尺寸（命中停顿冻结首帧），约 0.2 秒内碎裂淡出；
- 起手血聚约 6–8 帧；
- 地面爪痕和焦痕约 1 秒，焦坑约 1.5 秒；
- 爆炎裂き的火线约 0.2 秒烧到目标，旋柱持续约 0.6 秒；
- 爆血かかと落とし的穹顶约 0.2 秒长成，持续约 0.8 秒后从根部烧尽。
