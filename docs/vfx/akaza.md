# 猗窝座技能特效

目标：复刻《火之神血风谭》中猗窝座「破坏杀」的特效。参考拆解见 [akaza-reference.md](akaza-reference.md)。原有特效（`shockwave` / `compass` 贴图的通用绘制、命中时的罗针小环、`fighter_view.gd` 里的觉醒罗针）全部放弃。猗窝座的 29 招（含投技和新招）全部由新特效绘制，没有一招再走 `EffectsView` 的通用效果。

两种形态用两套颜色：

- 普通形态是无限列车篇的青蓝冲击；
- 觉醒（术式展开·罗针）后冲击转为无限城篇的蓝紫，脚下常驻雪花罗针阵，身体带一圈蓝紫火焰轮廓。

白热核心和白色气压弧在两种形态下相同。

2026-10-16 按用户意见重做了两处：

- **冲击爆**：原来是三层锯齿多边形，看起来像假水晶。现在改为离线烘焙的贴图：一团填实的蓬松光团，白热核心、青色主体，边缘只是一圈短而钝的毛边（不做成尖刺），外面射出黑色细墨线和几道淡白细线。
- **砸地**：空式·下落地和万叶闪柳原来是从地里掀起青色晶板，看起来像木板。现在改为地面碎裂：石板翘起后落回，被冲击从下方照成蓝色，同时碎石飞溅。

碎石只出现在真正砸地的两招（空式·下落地、万叶闪柳），用三面受光的多面岩块；普通命中、乱式、流闪群光、灭式和投技都不出碎石。晶屑换成柔和的光点。乱式的爆点对准猗窝座出拳的高度（上半身），不在攻击框中部。

## 结构

| 文件 | 作用 |
|---|---|
| `scripts/presentation/vfx/akaza_vfx.gd` | 挂在 `EffectsView` 下的 `AkazaVfx`。包括：五个绘制层；四个粒子池（火花、光点、碎石、烟尘）；命中爆闪；飞道具跟踪；通用画法（冲击爆、气压环、新月、光针、气旋、放射光、焦坑、沟痕、起手红光、碎石地裂、罗针阵、身体闪光、火焰轮廓）。`MOVES` 表把招式分派给各招式脚本 |
| `scripts/presentation/vfx/akaza/technique.gd` | 招式脚本基类。挂钩：`emit`（每个战斗帧生成粒子）、`draw`（按招式帧画形状）、`contact`（命中）、飞道具（`emit_shot` / `draw_shot` / `shot_ended`）、自定义爆闪（`draw_burst`）、`linger` / `draw_lingering`。工具函数：突进起点、锚点、超杀蓄力时钟、起手红光包络、以及对手在本地坐标中的位置（`target_local`） |
| `scripts/presentation/vfx/akaza/kit.gd` | 层序和配色（`tone` / `deep` 按形态取青蓝或蓝紫） |
| `fist.gd`、`kick.gd` 等 | 每类招式一个脚本，见下文 |
| `compass.gd` | 觉醒：罗针阵、发动演出、火焰轮廓。不属于任何招式，由觉醒状态和事件驱动 |
| `art/effects/akaza/` | 烘焙贴图，由 `tools/build_akaza_vfx_art.py` 生成（结果确定，可重复生成），导入时开启 mipmap：`shock-cyan.png`、`shock-violet.png` 是冲击爆，4 种变体 × 2 个阶段（密集 / 消散），每格 256px；`rocks.png` 是 4×4 格的岩块，灰色，绘制时按用途染色 |

层序（`EffectsView` 的 z 为 10，下表是相对值）：

| 层 | z | 混合 | 内容 |
|---|---|---|---|
| FLOOR | −9 | 普通 | 焦坑、沟痕、地裂纹、背排石板、觉醒罗针阵的深色底线 |
| SIGIL | −9 | 叠加 | 罗针阵、觉醒火焰轮廓（画在角色身后，只露出一圈光边） |
| GLOW | −1 | 叠加 | 外光（在两名角色之下，被打的一方仍然看得清） |
| FRONT | 0 | 普通 | 冲击爆主体和黑色墨线、白色气压弧和气压环、烟尘、碎石、前排石板、墨溅 |
| LIGHT | 0 | 叠加 | 爆闪核心光、冲击爆的淡光、白色细线、火花、光点、放射光、起手红光 |

## 规则

- 只读战斗状态，不改动任何战斗数据；测试在绘制前后比较快照。
- **粒子在 `consume` 里按战斗帧生成**，随机数按招式实例、帧号和槽位取种子；渲染帧率不影响结果。逐帧推进和成批推进得到的粒子完全相同，有测试保证。
- 形状跟随招式帧；粒子、爆闪和地面痕迹只随 `EffectsView` 传入的演出时间推进，所以命中停顿、超杀冻结、暂停和 KO 冻结时整幅画面静止。
- 起手红光只在必杀、超杀、MAX 和空中必杀的起手出现，约 7 帧。
- 多段招式中间几段的冲击爆偏小，末段放大（乱式、流闪群光、飞游星千轮、青银乱残光）。
- **冲击爆**（`shock`）：第一帧就是满尺寸（命中停顿会冻结这一帧），随后略微胀大，从密集阶段淡入消散阶段，并在寿命后半淡出。种子决定用哪种变体、转角和是否镜像。黑色墨线只出现在前半段。叠加光刻意压低（白闪只占中心一小块），白色细线短而淡，让青色光团而不是一团白光或一圈尖刺来表现冲击。多团爆点叠在同一处会发白，所以乱式每段命中只画命中爆点，招式自己的前端爆点只在打空时画。
- **碎石地裂**（`rubble`）：石板取自 `rocks.png`，以底边为轴背离落点翘起、升起，然后落回；背排画在角色身后，前排画在身前；地缝的蓝光只照亮石板底部。碎石（`debris_burst`）只由这两处砸地发出。
- 超杀和 MAX 自己画蓄力，`SuperView` 不再画通用能量球。
- **拳脚位置按画面实测**：`fist.gd` 的 `POSES`、`kick.gd` 的 `CURVES`，以及各招式脚本里的拳、脚坐标（空式的 `RELEASE` / `AIR_RELEASE`、灭式的 `FIST` / `PUNCH`、流闪群光的 `FOOT` 和两段曲线、飞游星千轮的踵弧、踏进冲拳的拳、万叶闪柳的落点、投技的 `HAND`、青银乱残光的 `STRIKE`），都是在美术 v3 动作片段的命中帧上用 `tools/build_vfx_fit_sheet.py` 量的（2026-10-16 重绘后重新测量；原来按 roster-v1 的画量）。v3 的猗窝座按原著身高缩小了，拳头离身体比旧画近约 9 单位。检查点 ④ 审阅后又量了一次：比例改为按架势帧锚定后，5B、5AA、jC、6B 整体缩小 4–12%，万叶闪柳放大约 6%；5C、6C 改成右手后手直拳，2C 改成背身的后手上勾拳，5D、2D、jD 改用近侧腿，这些招的拳脚位置都按新画重测（`tools/build_vfx_fit_sheet.py tips` 的前后对比）。第二、三轮审阅调整比例后又量了两次：万叶闪柳整体缩到约 0.9（落点 x 32），2D 扫腿脚尖在 x 27，5C、6C 的拳头和灭式出拳、空式出手点、2B 脚尖各移 1–3 单位。

### 术式展开·罗针（觉醒）

| 阶段 | 表现 |
|---|---|
| 发动（觉醒冻结 + 起动，共 30 帧） | 身上起手红光；脚下红色六重雪花阵从中心向外描出：中心六边形 → 主辐射线和菱形 → 枝杈与尖端小六边形 → 内外圆环。第 12–18 帧阵转为蓝紫，阵缘升起六道光柱，光点和尘烟飞散，身体泛起蓝紫光 |
| 持续 | 脚下一张蓝紫罗针阵跟随猗窝座缓慢旋转，跳起时变淡；他每打中一次，罗针阵闪亮一下。身体周围一圈闪动的蓝紫火焰轮廓，不时有火苗向上飘 |
| 结束 | 罗针阵约 0.35 秒淡出 |

罗针阵的颜色（检查点 ④ 审阅后加深）：线条先在 FLOOR 层用深紫墨色 `INK`（0.2, 0.09, 0.55，不透明度 0.8）画一遍，线宽 1.7 倍；再在 SIGIL 层叠加饱和的蓝紫光 `GLOW`（0.43, 0.33, 0.93）。原来只有叠加层的淡紫（`Kit.VIOLET`），在深色地面上显得发白。`compass_shape` 的 `ink` 参数默认为空，所以 MAX 的罗针阵不变。

发动按战斗帧计时（觉醒冻结期间也在推进），所以与渲染帧率无关。直接进入觉醒状态（例如练习模式恢复、测试）时不播发动，直接显示罗针阵。觉醒时 `awakening_effects` 仍对猗窝座隐藏，觉醒表现全部由 `compass.gd` 负责。

## 工具

- 实机录像：`tools/capture_moves.gd -- --character=akaza --no-cinematic`。
  - `--form=awakened` 录觉醒版，`BC` 录觉醒发动；
  - `5A>A>C` 这类派生串会等上一段命中再按下一键。录像工具已修正：等的是新一段的命中，不再把上一段的命中当成新的；
  - 新增 `hp:N` 设置对手的血量。长脚本会把木桩打空血，之后的招式会穿身而过，所以每组招式前加 `hp:1000`；
  - `guard:1` / `guard:0` 让对手从此按住后下蹲防 / 松开，用来录被防的效果（蹲防不会后退，中段和下段都能防住）。
- 贴图：`.venv\Scripts\python.exe tools/build_akaza_vfx_art.py [--preview <图>]` 重新生成 `art/effects/akaza/`，`--out <目录>` 可以先输出到别处比对。
- 参考抽帧：`tools/build_vfx_reference.py burst`，见 [akaza-reference.md](akaza-reference.md)。
- 拳脚对位：`tools/build_vfx_fit_sheet.py grid akaza <输出图> stand_light:2,3 …` 把片段画在 10 单位的局部坐标网格上；`tips akaza <片段…>` 逐帧打印剪影最前端（拳或脚）、顶点和前上方极点的局部坐标。美术 v3 重绘后用它重新测量各招式脚本里的拳脚位置。

## 测试

`tests/akaza_vfx_tests.gd`（`AKAZA VFX TESTS`）：

- 路由：五个绘制层；猗窝座的每一招（含新招和投技）都归 `AkazaVfx`，其他角色不归；超杀和 MAX 自己画蓄力；旧的罗针命中效果和觉醒罗针已删除；
- 每招的普通版和觉醒版：
  - 都会生成粒子；
  - 冻结时静止；
  - 绘制不改动战斗快照；
  - 命中有爆闪；
  - 粒子、爆闪和地面痕迹在 2.5 秒内全部消失；
  - 重置后状态清空；
- 投技：砸地时出现小坑和烟尘，之后全部清空；
- 飞道具：飞行中被跟踪并留下拖尾；空中版的碎石地裂只出现一次并留下小坑；地面版在射程尽头散开，不出地裂；
- 踏进冲拳的光针、灭式的冲击波：出拳期间头部始终超出攻击框前端；
- 觉醒：罗针阵随觉醒出现，觉醒冻结期间每个战斗帧推进一次，绘制不改动战斗；持续期间有火苗；觉醒结束后淡出并清空；没有觉醒事件时也能显示；重置后清空；
- 乱式、空式：逐帧推进和成批推进得到完全相同的粒子。
