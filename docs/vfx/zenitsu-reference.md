## 视觉语言

| 元素 | 观察 | 本游戏的对应 |
|---|---|---|
| 突进光束 | 黄白色粗光束，从起点直贯到善逸当前位置，前端是尖刺状星形，尾部渐细；身体被照成金色剪影；光束保持 6–10 帧后从尾部消散 | `ZenitsuVfx.beam`：白热内芯 + 金色主体 + 金色外光，前端 `star`；`body_flash` 金色 |
| 闪电 | 青白色锯齿折线，有分叉，粗细不一；每隔几帧整条重新劈一次，不是平滑动画 | `bolt.gd`（中点位移 + 分叉），按战斗帧取种子，所以只随游戏帧闪烁 |
| 命中 | 漫画式星形爆闪（长短刺交替、带描边），金色 X 字闪光，四散的细长金色光线，金色火花，地面与身体的黑色碎块 | `strike`：`star` + `cross` + `bolts` + `rays` + `sparks` + `debris` |
| 居合弧 | 金色新月形刀光，白色内芯，外沿一圈蓝色细边和闪电毛边；普通技较细，偏青白 | `crescent`：`electric`（轻技）/`gold`（重技、觉醒） |
| 起手蓄力 | 脚下噼啪的小闪电；空中版起手时身体被一道蓝色光柱罩住 | 地面：脚边短闪电；空中：`pillar` |
| 速度线与焦痕 | 突进时身后有深色速度线，地面留下一道黑色焦痕 | `speed_lines`、`scorch` |
| 四方斩 | 腰部高度一圈扁平的蓝色闪电环，远侧在角色身后 | `lightning_ring`（回身斩借用） |
| 火雷神 | 闪电偏暖色，命中处是品红/橙色锯齿爆闪 | 热界雷用 `heat` 风格（金色主体 + 橙色外光） |
| 八连/六连 | 多条光束在敌人周围折线穿插，每个折角一个星形；最后一击巨大爆闪和放射光线 | `sixfold.gd`：六段折线光束，折角星形，末击放大 |

## 时间

- 突进光束：出现约 2 帧，保持 6–8 帧，再用约 10 帧从尾部消散；
- 星形爆闪：首帧就是最大尺寸，约 8–10 帧淡出（命中停顿冻结在首帧，所以首帧必须能看清）；
- 闪电：约每 3–4 帧重劈一次；
- 多段必杀：中间几段爆闪偏小，最后一段最大，避免画面被盖满。
