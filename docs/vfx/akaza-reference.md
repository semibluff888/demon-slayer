## 招式要点

- **空式（20:29）**：红光起手 → 连续直拳，拳前白色气旋 → 远处目标身上爆开青白星爆，四周白色气压弧；末击把对手打飞，空中拖出白色弧线。
- **空式·空中（20:33）**：跳起倒转身体，向斜下方连续出拳；每拳一团蓝色气旋，青色彗星状气拳斜下飞到对手处炸开。
- **乱式（20:37）**：红光加墨溅起手 → 贴身乱打，对手周围接连爆开三四团大尖刺火团，脚下黑灰烟尘滚滚 → 末击一道巨大白色冲击和弧形气浪，碎石四溅。
- **罗针（20:43）**：红色雪花阵 → 品红光柱 → 青色阵铺满地面，白色光柱和晶屑喷涌 → 对手周围巨大漩涡气浪与透明穹顶冲击，天色变暗，晶屑漫天；阵纹在地面停留。
- **灭式（20:51）**：蹲身蓄力，拳前蓝白星爆和两道大弧 → 一道白色细线闪过 → 贴地撕开地面的白青冲击波，掀起黑色碎石与烟尘，对手被巨大爆炸吞没 → 地面留下深色沟痕。
- **罗针（无限城，20:58）**：身体被蓝焰包裹，蓝紫色大环弧绕身旋转；贴地一道白色针线；罗针阵先红后蓝，蓝焰光柱升起。
- **奥义特写（21:01）**：脚下罗针阵展开，雪花纹瞳孔特写，青色放射速度线大爆发。
- **流闪群光（21:06）**：前踢爆出蓝紫尖刺火团 → 一道长针形蓝色光束突进，末端青色星爆 → 上踢时巨大蓝紫弧与灰色气浪，碎石，地面沟痕。
- **万叶闪柳（21:14）**：红光起手 → 高跳 → 下砸时竖直蓝紫光柱 → 晶簇地裂 → 焦坑。长按版和空中版相同，只是光柱更长。
- **鬼芯八重芯（21:29）**：白色残影突进，地面灰色尖刺尘浪；每击一团青紫尖刺火球，末击打飞。
- **飞游星千轮（21:35）**：红色 X 针线起手 → 白色残影突进，身前巨大白色新月弧 → 扫腿时贴地一圈白色扁环，命中处蓝紫爆，灰色尘柱。

## 时间

- 起手红光约 6–8 帧；
- 冲击爆首帧就是最大尺寸，约 8–10 帧淡出（命中停顿冻结首帧，所以首帧必须能看清）；
- 烟尘约 0.6 秒散尽；
- 晶板约 0.5 秒沉回，焦坑和沟痕停留约 1.5 秒；
- 多段乱打中间几团偏小，末击最大。
