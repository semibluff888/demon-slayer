# 善逸技能特效

目标：复刻《火之神血风谭》中善逸的雷之呼吸特效。参考拆解见 [zenitsu-reference.md](zenitsu-reference.md)。原有特效全部放弃，所有刀斩普通技、必杀、空中必杀、超杀和 MAX 都由新特效绘制；体术普通技（B/D）和投技仍走 `EffectsView` 的通用命中效果。觉醒（雷之呼吸·神速）时闪电由青白色变为金色。

## 结构

| 文件 | 作用 |
|---|---|
| `scripts/presentation/vfx/zenitsu_vfx.gd` | 挂在 `EffectsView` 下的 `ZenitsuVfx`：四个绘制层、粒子池（金色火花、电光微粒、碎块）、命中爆闪，以及光束、新月、闪电、星形、X 字、放射光线、速度线、焦痕、光柱、闪电球、闪电环等通用画法；`MOVES` 表把招式分派给各招式脚本 |
| `scripts/presentation/vfx/zenitsu/technique.gd` | 招式脚本基类：`emit`（每个战斗帧生成粒子）、`draw`（按招式帧画形状）、`contact`（命中）、突进起点记录、锚点、超杀蓄力时钟、`linger` / `draw_lingering` |
| `scripts/presentation/vfx/zenitsu/kit.gd` | 层序和配色 |
| `scripts/presentation/vfx/zenitsu/bolt.gd` | 闪电几何：中点位移折线、分叉、闪电环；同一种子永远得到同一道闪电 |
| `iai_cut.gd` 等 | 每类招式一个脚本：`iai_cut`、`thunderclap`、`rising_iai`、`turn_slash`、`distant_thunder`、`sixfold`、`godspeed` |

层序：

| 层 | z | 混合 | 内容 |
|---|---|---|---|
| BACK | −9 | 普通 | 地面焦痕、闪电环的远侧半圈 |
| GLOW | −1 | 叠加 | 光束、闪电和新月的外光（在两名角色之下，被击中的角色仍然清楚） |
| FRONT | 0 | 普通 | 光束主体、新月、星形爆闪、速度线、闪电白芯、碎块 |
| LIGHT | 0 | 叠加 | 闪电本体、X 字闪光、放射光线、火花、电光微粒、身体闪光 |

## 规则

- 只读战斗状态，不改动任何战斗数据；测试在绘制前后比较快照。
- **粒子在 `consume` 里生成**。`main.gd` 每走一个战斗帧就调用一次 `consume`，所以每一帧的粒子都按战斗实际位置生成，突进起点也是战斗里真实的起点。不论渲染帧率是多少，结果都一样（测试逐帧和成批两种方式比较）。
- 形状跟随招式帧，闪电的种子按战斗帧计算，所以闪电只随游戏帧闪烁，与渲染帧率无关。
- 粒子和爆闪只随 `EffectsView` 传入的演出时间推进：命中停顿、超杀冻结、暂停和 KO 冻结时整幅画面静止。
- 超杀和 MAX 自己画蓄力，`SuperView` 不再画通用能量球。
- 多段超杀中间几段的命中爆闪缩小，最后一段放大。

## 招式

### 刀斩普通技与稻魂（5A/5C、2A/2C、jA/jC、5A > A > C）

沿原有刀路曲线（`EffectsView.CUT_CURVES`）画新月形刀光：轻技为细的青白色电光，重技为金色主体 + 白芯 + 蓝色外沿和闪电毛边。出刀时从外沿甩出金色火花。稻魂末段有两刀，第二道新月反向扫回。

### 霹雳一闪（236A/C）、低身斩（3C）、霹雳一闪·空（j.236A/C）

| 阶段 | 表现 |
|---|---|
| 起手 | 脚边噼啪的短闪电，身体逐渐变金；空中版是一道罩住全身的蓝色光柱 |
| 突进 | 从突进起点到善逸当前位置的粗光束（白热内芯、金色主体），前端尖刺星形，两道闪电沿光束奔走；身体金色闪光，身后深色速度线，地面一道黑色焦痕；前端不断甩出火花 |
| 收尾 | 光束保持约 2 帧，再用 12 帧从尾部消散 |
| 落地 | 空中版在落地那一刻结束招式，光束交给 `draw_lingering` 继续消散；落地处迸出火花、碎块和星形 |

低身斩的光束贴近地面、更细。

### 居合·上撩（623A/C）、热界雷（6C）

从身前低处向上越过头顶的金色新月，一道带分叉的闪电从地面穿过刀光向上劈。上撩会离地，所以刀光留在出刀的位置。热界雷用暖色（金色主体 + 橙色外光），像热闪电。

### 居合·回身斩（214B/D）

后撤时身体泛起冷色电光；第一刀在腰部高度甩出一圈扁平的闪电环（远侧半圈在角色身后），第二刀是一道宽的金色横扫。

### 远雷（j.214B/D）

空中急停时被一团噼啪作响的闪电球包住；随后向前下方闪斩，留下光束，同时一道闪电从天空劈到闪斩的起点。光束和落地衔接与空中霹雳一闪相同。

### 霹雳一闪·六连（超杀）

超杀冻结期间，金色闪电球和地面闪电环逐渐成形；六刀各是一段光束，沿善逸的前进路线上下折线穿插，每个折角都有一个星形爆闪；最后一刀命中爆闪最大，随后六道光束一起消散。

### 霹雳一闪·神速（MAX）

冻结期间是一道白金色光柱和更大的闪电球；发动后是一道粗光束，冲过善逸身前 80 单位，三道粗闪电沿光束奔走；收招时前端放射出一圈金色光线，光束慢慢消散。

## 工具

- 实机录像：`tools/capture_moves.gd -- --character=zenitsu --no-cinematic`。`--no-cinematic` 让超杀留在游戏画面里，而不是播放预渲染视频。`meter:N` 补满气，`home:N` 把善逸放回固定位置，`--form=awakened` 录觉醒版。
- 参考抽帧：`tools/build_vfx_reference.py burst`，见 [zenitsu-reference.md](zenitsu-reference.md)。

## 测试

`tests/zenitsu_vfx_tests.gd`（`ZENITSU VFX TESTS`）：

- 路由：四个层、每个新特效招式都归 `ZenitsuVfx`，体术和投技仍走通用效果，超杀自己画蓄力；
- 每个招式的普通版和觉醒版都会生成粒子；冻结时静止；绘制不改动战斗快照；命中有爆闪；一秒半内全部消失；重置后状态清空；
- 空中突进：落地时光束交接、落地爆闪只出现一次、光束消散完毕后清空；
- 逐帧推进和成批推进得到完全相同的粒子。
