# 祢豆子技能特效

目标：复刻《火之神血风谭》中祢豆子「血鬼术·爆血」的特效。参考拆解见 [nezuko-reference.md](nezuko-reference.md)。原有特效全部舍弃（2026-10-17 用户确认）：`EffectsView` 的 `blood` 风味（命中花瓣、刀光菱形、普通技菱形）、`blood-flame` 贴图的通用绘制和 `awakening_effects.gd` 里祢豆子的光环、手部和地面层都已删除或对她隐藏。祢豆子的 29 招（含投技和新招）全部由新特效绘制。

两种形态用两套颜色：

- 普通形态是爆血的粉红火焰；
- 鬼化（觉醒）后火焰偏血红、更深，身体带一圈闪动的深红火焰轮廓。

白色气浪弧、漫画冲击星和黄白十字闪在两种形态下相同。

## 结构

| 文件 | 作用 |
|---|---|
| `scripts/presentation/vfx/nezuko_vfx.gd` | 挂在 `EffectsView` 下的 `NezukoVfx`。包括：五个绘制层；四个粒子池（火星、血屑、碎石、烟尘）；命中爆；通用画法（血焰爆、火焰带、爪痕、气浪环、新月、光针、气旋、放射光、十字闪、冲击星、火柱、火焰旋柱、火焰穹顶、焦坑、地面爪痕、焦痕、碎石地裂、起手血聚、身体闪光、火焰轮廓）。`MOVES` 表把招式分派给各招式脚本 |
| `vfx/nezuko/technique.gd` | 招式脚本基类。挂钩：`emit`（每个战斗帧生成粒子）、`draw`（按招式帧画形状）、`contact`（命中）、`draw_burst`、`linger`。工具函数：突进起点、锚点、超杀蓄力时钟、起手血聚包络、对手在本地坐标中的位置 |
| `vfx/nezuko/kit.gd` | 层序和配色（`tone` / `deep` 按形态取粉红或深红） |
| `claw.gd`、`kick.gd` 等 | 每类招式一个脚本，见下文 |
| `demon.gd` | 鬼化：发动演出、火焰轮廓。不属于任何招式，由觉醒状态和事件驱动 |
| `art/effects/nezuko/` | 烘焙贴图，由 `tools/build_nezuko_vfx_art.py` 生成（结果确定，可重复生成），导入时开启 mipmap：`blaze-pink.png`、`blaze-crimson.png` 是命中爆，4 种变体 × 2 个阶段（密集 / 消散），每格 256px；`flame-strip.png`、`claw-strip.png` 是给丝带用的火焰条和爪痕条（U 沿笔画、V 横跨，4 行粉红 + 4 行深红）；`flakes.png` 是 4×4 格的血屑；`star.png` 是 2 格白色冲击星。碎石借用猗窝座的 `art/effects/akaza/rocks.png` |

层序（`EffectsView` 的 z 为 10，下表是相对值）：

| 层 | z | 混合 | 内容 |
|---|---|---|---|
| FLOOR | −9 | 普通 | 焦坑、地面爪痕、焦痕、背排石板 |
| SIGIL | −9 | 叠加 | 鬼化火焰轮廓（画在角色身后，只露出一圈光边）、脚下地面红光 |
| GLOW | −1 | 叠加 | 外光（在两名角色之下，被打的一方仍然看得清） |
| FRONT | 0 | 普通 | 火焰带和爪痕主体、命中爆主体和黑红墨刺、白色气浪、冲击星、烟尘、碎石、血屑、前排石板 |
| LIGHT | 0 | 叠加 | 火焰的光、火星、十字闪、放射光、起手光球、白热裂纹 |

## 规则

- 只读战斗状态，不改动任何战斗数据；测试在绘制前后比较快照。
- **粒子在 `consume` 里按战斗帧生成**，随机数按招式实例、帧号和槽位取种子；渲染帧率不影响结果。逐帧推进和成批推进得到的粒子完全相同，有测试保证。
- 形状跟随招式帧；粒子、命中爆和地面痕迹只随 `EffectsView` 传入的演出时间推进，所以命中停顿、超杀冻结、暂停和 KO 冻结时整幅画面静止。
- 起手血聚只在必杀、超杀、MAX 和空中必杀的起手出现，约 7 帧。
- 多段招式中间几段的命中爆偏小，末段放大（回旋踢、回旋踢·空、连续踢末段、超杀、MAX）。
- **命中爆**（`blaze`）：第一帧就是满尺寸，随后略微胀大，从密集阶段淡入消散阶段。白色叠加光刻意压低（第一轮实机截图里白光盖过了火焰），让粉红火焰而不是一团白光表现冲击；重击加十字闪，必杀加放射光。
- **突进特效领先身体**：爆血飞踢的火焰彗星、滑踢的贴地火线，头部都越过攻击框前端（有测试保证）；俯冲踢的火尾沿俯冲方向领先脚尖。
- **特效延伸到攻击框**（用户审阅，2026-10-18）：v3 的手脚画得比判定框短，爪痕、脚弧停在手脚上，看起来打不到对手。`Technique.reaching(move, keys, share)` 把三点笔画（起点、控制点、终点）从最靠后的点向前拉长，直到最前端到达攻击框前沿的 `share`（默认 0.9），起点仍在手边或支撑脚旁。
  - 用于爪类和踢类普通技、连续踢；
  - 超杀和 MAX 前几脚用 0.8，超杀的升空踢收尾和 MAX 的踵落不拉长；
  - 回旋踢的弧浪绕到身前时半径张大到攻击框前沿，回旋踢·空的新月半径同样至少到前沿（`box_front`）；
  - 坐标按 `body_scale()` 换算，鬼化形态同样适用。
- 碎石只出现在真正砸地的三处：俯冲踢落地、投技摔地、MAX 的踵落，并且只出现一次。
- 超杀和 MAX 自己画蓄力，`SuperView` 不再画通用能量球。
- **跟随角色缩放**：`NezukoVfx.body_scale()` 取她的 `model_scale`（0.85），鬼化时再乘觉醒的 `form_scale`（1.15）；招式脚本里的爪、脚坐标都按 1.0 的画量。缩放直接从战斗状态和角色定义计算，不读角色视图（视图在开局第一帧还没同步，读它会让粒子位置随渲染节奏变化）。
- **爪、脚位置分形态拟合**（美术 v3，2026-10-18）：
  - 普通形态换成了 v3 重绘，鬼化形态仍用原来的图集。v3 的画更小（待机头顶 61 单位，鬼化图 73），手脚位置也不同，一套坐标没法同时对上两种画。
  - 招式脚本的爪、脚、脚跟、抓手位置写成两份：常量本身对应 v3 普通形态；`DEMON_` 开头的一份对应保留的鬼化图，就是重绘前在旧图上量的值。
  - `Technique.fit(f, normal, demon)` 按 `NezukoVfx.demon_art(f)` 取值。这个判断直接用战斗状态（和 `body_scale` 相同：鬼化中或在放觉醒收招），不读角色视图。
  - 绕身体的形状（起手血聚的光球和墨刺、超杀蓄力的火舌螺旋、升空踢的弧、2D 的贴地环、抓手的墨溅）按 `NezukoVfx.drawn(f)` 缩放：v3 是 0.84，鬼化是 1。
  - v3 的位置在打包后的图集上量：最前点用 `tools/build_vfx_fit_sheet.py tips nezuko …`；手的位置取脸部以外的皮肤色块（`anatomy` 的皮肤类）。每道笔画都保持它在旧图上相对爪尖或脚尖的形状，再按 0.84 缩放。
  - MAX（`kakato_max.gd`）只在鬼化形态出现，坐标不变。
  - 用 `tools/capture_tanjiro_vfx.gd -- --character=nezuko --forms=normal --hd --keep-frames` 逐帧录像核对，爪痕、脚弧都落在画出来的手脚上。

| 踢类普通技（5B/5D、2B/2D、jB/jD） | `kick.gd` | 沿脚路的白色新月；重踢沿脚路拖出一道粉红火舌，支撑脚扬尘；2D 贴地扁环加尘带 |

### 鬼化·爆血（觉醒）

| 阶段 | 表现 |
|---|---|
| 发动（觉醒冻结 + 起动，共 30 帧） | 前 12 帧血聚（光球、墨刺、身体泛红）；第 12 帧血焰冲天：火柱从脚下升起，血屑、火星飞散，地面尘环；身体闪深红光 |
| 持续 | 身体周围一圈闪动的深红火焰轮廓，不时有火星和血屑向上飘；脚下一团淡淡的深红地光，跳起时变淡 |
| 结束 | 火焰轮廓约 0.35 秒淡出 |

发动按战斗帧计时（觉醒冻结期间也在推进），所以与渲染帧率无关。直接进入觉醒状态（例如练习模式恢复、测试）时不播发动，直接显示火焰轮廓。觉醒时 `awakening_effects` 对祢豆子隐藏（同猗窝座）。

## 工具

- 实机录像：`tools/capture_moves.gd -- --character=nezuko --no-cinematic`，`--form=awakened` 录鬼化版。派生写作 `5B>B>D`。
- 贴图：`.venv\Scripts\python.exe tools/build_nezuko_vfx_art.py [--preview <图>]` 重新生成 `art/effects/nezuko/`，`--out <目录>` 可以先输出到别处比对。
- 参考抽帧：`tools/build_vfx_reference.py burst`，见 [nezuko-reference.md](nezuko-reference.md)。
- 爪脚对位：`tools/build_vfx_fit_sheet.py tips nezuko <片段…>`。

## 测试

`tests/nezuko_vfx_tests.gd`（`NEZUKO VFX TESTS`）：

- 路由：五个绘制层；祢豆子的每一招（含新招和投技）都归 `NezukoVfx`，其他角色不归，其他重制层也不碰她的招；超杀和 MAX 自己画蓄力；旧的 `blood` 风味已删除；贴图都已导入；
- 每招的普通版和鬼化版：都会生成粒子；冻结时静止；绘制不改动战斗快照；命中有爆闪；粒子、命中爆和地面痕迹在 2.5 秒内全部消失；重置后状态清空；
- 投技：摔地时地面碎裂、留下焦坑和烟尘，之后全部清空；
- 俯冲踢：只在落地时碎裂一次，落地前没有，并留下焦坑；
- 爆血飞踢（轻 / 重）和滑踢：出招期间火焰头部始终越过攻击框前端；
- 超杀末段有火线、旋柱和焦痕，MAX 末段有穹顶、地裂、焦坑和冲击星；前面几段没有；
- 鬼化：发动随觉醒出现，冻结期间每个战斗帧推进一次，绘制不改动战斗；持续期间有火星和血屑；旧光环层保持隐藏；结束后淡出并清空；没有觉醒事件时也能显示；重置后清空；
- 回旋踢、爆血飞踢、连续踢末段：逐帧推进和成批推进得到完全相同的粒子。
