## 默认键位与菜单

| 动作 | P1 | P2 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| A／B／C／D | T／Y／G／H | 小键盘 4／5／1／2 |
| 菜单确认／返回 | T／Y | 小键盘 4／5 |
| 暂停 | Esc | Esc |

数字主键区和小键盘分别识别。键位按物理位置保存；改键后标题菜单、选人、选地图、暂停、帮助及练习提示同步使用新键位。手柄战斗仍为 X／A／Y／B 对应逻辑 ABCD，菜单为 A 确认、B 返回。

主菜单现为「单人对战」「双人对战」「自由练习」「帮助」「游戏设置」。标题已绘在海报内，不叠加重复标题文本。选人、选地图的设备按钮、设备弹层和 Y 快捷入口已移除；双方独立选择、锁定、返回流程保留。

游戏设置提供静音、主音量，以及 P1／P2 各自的四方向和 ABCD 改键。点击键位后按下新键，Esc 或手柄 B 取消捕获；保留键或与另一动作重复的键会给出冲突提示，不覆盖原绑定。可恢复一方或双方默认；若一方默认被另一方占用，会提示先恢复双方。Esc、F1／F2／F3、Backspace 等系统操作键保留。

声音、音量与键位即时生效，自动保存在 `user://settings.cfg`，即 Godot 用户数据目录中的配置文件。存储失败会显示提示；损坏或冲突的键位配置安全回退至默认。F2 静音与设置页、保存文件同步。

控制器下拉选项放在游戏设置内，同一手柄不能同时分配两方。手柄断线自动暂停；仍可用键盘或鼠标进入设置切回键盘。设备分配保留在当前会话，声音和键盘映射跨启动保存。设置页支持鼠标、键盘、手柄焦点操作；键盘改键的具体按键仍需通过键盘输入。

暂停菜单新增「游戏设置」。进入设置后战斗与演出保持暂停；退出设置返回暂停菜单，再手动继续。修改键位和切换控制器时清理待执行输入，避免恢复对战时误放招式。

## 升龙接奥义／MAX

现行路线仍为 **5A → 5C → 623A/C → 236236A/C 或 236236A+C**。这是升龙命中后的取消，消耗 1／3 格气，不需要等待升龙落地后重新起招。

借鉴格斗游戏的命中确认、停顿输入和动作缓冲方式，分别调整识别窗口与招式取消窗口；以下为本项目参数，并非拳皇或街霸某个版本的官方帧表。

| 参数 | 修改前 | 现在（60 Hz 逻辑） |
| --- | ---: | ---: |
| 升龙有效期之后的取消余量 | 0 帧 | 收招前 12 帧，新增约 0.2 秒 |
| 双 236 整段识别 | 36 帧 | 42 帧，约 0.7 秒 |
| 双 236 最后方向到攻击 | 6 帧 | 12 帧，约 0.2 秒 |
| 已识别奥义／MAX 的执行缓冲 | 6 帧 | 10 帧，约 0.167 秒 |

升龙必须实际命中。挥空和被防不能取消；超过取消窗口的奥义输入会清除，避免缓冲到收招结束后单独放出。命中停顿期间仍可输入方向和攻击，动作缓冲不在停顿中耗尽。普通攻击、普通必杀的执行缓冲仍为 6 帧，623 识别仍为 20 帧，组合键容差仍为 2 帧。

此前「一进入收招就不能取消」的描述已不适用：现在早期收招也可取消。命中后继续输入双 236 即可，仍不要等完整动作收完。42 帧是方向序列的识别上限，不代表每次命中后都有 42 帧取消时间；实际还受取消截止时点限制。

取消时攻击方停止继续上升并自然下落；仍在空中受击硬直的受方获得小幅滞空，让较晚取消的奥义来得及衔接。已倒地目标不能拾取，追击次数不增加。已命中的多段奥义在接近浮空目标时限制向前移动，修复善逸六连从对手下方冲过、遗漏后续段的问题。

四人的轻重升龙高度、伤害、耗气和对空保护保持原样。奥义／MAX 全段仍为 **280／445** 伤害，消耗 **100／300** 气。

### 键盘练习

P1 面朝右、默认键位时：

1. 近身按 **T（5A）→ G（5C）**，每次攻击命中后接下一招。
2. 输入 **→↓↘ + T 或 G（623A/C）**。
3. 升龙命中后继续输入 **↓↘→↓↘→ + T 或 G** 接奥义；最后同时按 **T+G** 接 MAX。朝左时水平镜像。

方向对应 WASD，右下是同时按 S+D；到右方向时松开 S。相同攻击键再次出招前先松开再按，MAX 的两键尽量同时按。自由练习可用「首击后防」检查连段是否断开，气槽设为 3 格或无限。

### 实测范围

新增取消专项 **2176 项**通过，其中 **512 组路线**覆盖：四人全部 16 种对阵、左右朝向、中场／版边、轻／重升龙、奥义／MAX、命中后 0／6 帧反应延迟。双 236 每个方向保持 3 帧，所有路线完整命中，首击后对手持续按后也无法插入防御。另检验方向识别边界、挥空、被防、过期输入与延迟落地后的耗气。

实机录像使用 6 帧反应延迟及每方向 3 帧，通过真实方向／ABCD 输入驱动识别器，没有直接切换招式。以 60 Hz 运行、30 FPS 无声捕获。
