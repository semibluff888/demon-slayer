# 四角色、三地图与街机菜单

当前角色按炭治郎、善逸、祢豆子、猗窝座展示。新增的祢豆子和猗窝座各有 21 个战斗资源（12 普通技、6 必杀、2 奥义、1 投技）和 42 组独立动作，共 342 帧／人。普通形态保留竹筒；觉醒角与藤纹只随祢豆子的 MAX 动作及专用特写出现，完成、受击、KO、重置会离开该动作。

两张新地图为无限城和游郭夜街，和藤袭之庭共三张。它们共用原有场地边界、地面高度、固定 3 倍人物比例和横向镜头。初始选择藤袭之庭，再战和练习重置保留地图。

## 操作与流程

主菜单保留三个模式、指南和声音。选人页左右展示各自立绘，中央 VS，下方共享头像网格。头像固定为 96×88 逻辑像素，六列、两行可视，超过十二人滚动，活动光标自动进入可视区域。四人时居中排列，同角色对战显示双光标。

| 设备 | 移动 | 确认 | 返回 | 设备设置 |
| --- | --- | --- | --- | --- |
| 键盘 1 | WASD | F | G | 点设备，或 Tab 聚焦 |
| 键盘 2 | 方向键 | J | K | 同上 |
| 手柄 | 十字键／左摇杆 | A／Start | B | Y |
| 鼠标 | 点击头像、玩家栏、场景 | 确认／开战 | 返回按钮 | 设备按钮 |

从标题用手柄进入模式会把该手柄分配给 P1，本地双人优先将另一个已连接手柄分给 P2。设备弹层使用原生控件。未分配的手柄也能用 Y 打开设备设置。

单人和练习由 P1 依次确认双方，本地双人由各自设备独立控制和锁定。双方就绪后进入地图页，仅 P1 可改变场景与开战。返回选人保留人物并清除锁定。重复设备或断线禁止开战；地图页断线回到选人；战斗断线暂停，重新连接后须主动继续。

## 目录与扩展

- 在 `resources/characters/` 注册 `CharacterDefinition`，提供稳定 ID、`roster_order`、名称、12 普通技、必杀映射、投技、状态动画与资产目录。无需编辑选人页名单。
- `CombatCatalog` 按展示顺序及 ID 排序；`VisualCatalog.characters` 按 ID 查询。主菜单展示目录前四人，选人网格展示完整目录。
- `VisualCatalog.new(false)` 只准备菜单素材。`prepare_match(ids, stage_id)` 加载所选动作和地图，并释放其他角色图集／场景纹理。镜像对战共享同一图集。
- `resources/stages/` 的 `StageVisual` 定义 ID、排序、资产目录、名称、氛围。`catalog.stages[id]` 查询资源，`WorldView.set_stage(id)` 切换，`stage.json` 提供尺寸、分块和采样区域。
- `MovePresentation.cut_in_path` 支持单独特写；祢豆子 MAX 使用 `awakened-portrait.png`。原两位角色的书法招式标题继续使用原资源，新角色名称由 Godot 字体绘制。
- 制作导入器从任务清单读取角色与场景，`import_character_atlas.py` 接受已注册角色 ID。新角色若沿用当前战斗机制，只需注册资源并提供动作清单，无须修改菜单或战斗状态机。

## 生图与离线复现

采用 **imagegen 提示词规范 + 项目 CPA API/CLI 流程**，模型为 `gpt-image-2`，通过项目保存的 `Invoke-CpaImage.ps1` 调用安装技能中未改动的 `image_gen.py`。离线构建不需要接口、凭据或网络。

[提示词、原图与逐项记录](../output/imagegen/roster-v1/index.html)保留全部制作版本。清单共有 121 次生成输出，其中 5 组不合格动作保留为 `rejected-animation`，最终使用 116 份来源。费用没有可核实返回值，记录为 null；实际尺寸以记录为准，不把请求尺寸当成实际输出。

目录 `output/imagegen/roster-v1/`：

| 路径 | 内容 |
| --- | --- |
| `jobs.json`、`profiles.json` | 生成清单、角色身份与抠图底色 |
| `prompts/`、`raw/`、`references/` | 提示词、原始输出、场景细节参考 |
| `records/` | 请求状态、实际尺寸、SHA256、采用／拒绝记录 |
| `imports/` | 每帧源区域、根节点、比例和归一化边界 |
| `calibration.json` | 受投骨盆与落地锚点 |
| `scale-calibration.json` | 全动作实体比例、逐帧绘制修正、原图哈希 |
| `portrait-calibration.json` | 面部等比裁切及觉醒独立特写选区 |
| `review/` | 可重建的逐帧接触表、GIF 和总览 |

祢豆子使用青色底，保护粉色衣服与爆血；猗窝座使用绿色底，保护粉发与蓝纹。动画归一化到 1024×640 画布、脚底锚点 (448,568)、340 像素站姿标尺，对应 70 世界单位。裁切只分离原画。实体比例使用独立校准表，原图内部的大小漂移在离线导入时逐帧修正；不再按网格高度估算身高。旋转动作按骨盆校准，受投末四帧贴地。详见[角色体型修复](roster-scale-fix.md)。翻滚使用既有 28 帧无敌／回收时序。四组受投重新生成，纠正角色身份与落地收尾；祢豆子蹲防另行重绘，匹配低位姿态。

每张新地图先确定全景，再取 5×2 个带重叠的参考区域生成细节。离线通过受限仿射配准与羽化合成 6144×1536 连续图，切为四块 1552×1552 纹理（1536 核心＋每侧 8 像素采样边）。像素测试验证分块及留边完整重建全景。原始主图实际为 2172×724；细节输出尺寸和配准矩阵逐项保存在 `stage.json`。
