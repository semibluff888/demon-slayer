## 播放及结算

- 首次有效命中锁定同一攻击实例；已结算的首击不再重复扣血，后续伤害使用现有逐段伤害、防御倍率和回气逻辑，按视频进度分段结算。
- 视频及释放者收势期间暂停普通战斗步进、回合倒计时、觉醒计时、AI 与战斗输入；不允许缓存按键后续自动出招。非致命必杀的释放者在 0.65 秒收势完成后恢复移动、跳跃和出招；致命必杀保持双方操作锁定直至胜利结算结束；敌人在剩余收尾时间内独立播放倒地、不能操作或被重复击中。血条和连击随已结算段数更新。
- 画面只显示视频、上方头像/血条/回合信息和连击提示。视频中隐藏下方气槽、操作提示、练习信息、旧奥义书法与特效；视频及 KO 定格结束、进入地图收尾时恢复完整 HUD 和操作提示，暂停菜单始终可正常打开。
- Esc / 手柄暂停、帮助和设置期间视频与声音暂停；音量和静音即时生效。设置开关对下一次命中生效，当前演出正常完成。
- 致命必杀在视频末尾显示一次 KO，定格 0.8 秒后接 1.15 秒地图收尾；胜负计分仍延后到收尾完成，再直接进入胜利动作，跳过普通 KO 的第二次提示、冻结和击飞。重开、回标题、重新选人、重置练习会清理播放器、定格纹理及演出锁定。
- 缺失视频不会进入演出捕获；解码器若停滞会转入本地收尾，避免比赛锁死。

## 当前地图收尾

视频后的 1.15 秒使用本游戏现有角色精灵帧和当前地图重新编排，不包含原视频的敌人或场景图。动作是适配现有 2D 资源的近似复刻，并非原作 3D 动画逐像素移植：

- 善逸：背对敌人的收刀姿态；神速增加短落地；敌人坠落倒地；竖向雷电素材（按反馈旋转 180 度）与落尘淡出，移除地面白色斩线和额外绘制的白色竖直电弧。
- 炭治郎：水系收刀与水花波纹；火系落地蹲姿、站起与火焰余波。
- 祢豆子：爆血收势、觉醒形态短收尾（均跳过踢腿帧），敌人倒地与粉红火焰余波。
- 猗窝座：冲拳收势、敌人倒地、蓝色冲击与罗针式余波；两个招式共用此收尾。

释放者的收势在 0.65 秒内播放完毕，非致命情况下交还操作，致命情况下保持最后收势帧；整体收尾仍为 1.15 秒，敌人的下落与倒地帧时序保持不变。非致命收尾完成仅解除敌人姿势覆盖，不再清空双方贴图、重置释放者位置或输入，避免空白帧以及打断已开始的跳跃、攻击。地图动画在视频及 KO 定格结束时恢复。所有收尾技能贴图使用独立的加法混合层，消除黑色矩形背景，不影响视频的正常显示。

动作、姿势帧、残留特效、切点均集中在 `resources/cinematics/catalog.json`，方便后续替换。视频内的原作背景与对手暂时保留，按本次约定后续再处理。

## 致命必杀定格与觉醒映射

普通祢豆子奥义使用爆血；发动时已觉醒的祢豆子奥义通过 `awakened_profile` 复用 MAX 的视频、音轨、时长及觉醒收势。实际招式 ID 与演出配置 ID 分离，伤害段数、连击、耗气和回气沿用实际奥义：觉醒普通奥义耗1格、伤害110%，保留觉醒；觉醒MAX耗1格及剩余觉醒，立即结束强化。演出按发动快照选择形态，不能用所复用的视频决定伤害或耗气。资源生成脚本保留该引用，不新增重复视频。

致命演出的状态顺序为 video → ko_freeze → tail → round_end。视频完整播放到尾部，缓存末段最后有效解码帧并复制成独立纹理；停止播放器后保持该图像 0.8 秒。0.08 秒闪白、0.16 秒 KO 字样缩放和轻震屏配合一次现有 KO 音效，顶部 HUD 不受震动、压暗和闪白影响。猗窝座片尾有纯白过场，通过 `ko_frame_time = 14.8` 缓存尾段冲击画面，视频和音轨仍完整播放后才显示定格。最后 0.12 秒淡出覆盖层，底下预先摆好地图收尾首帧；淡出结束后才开始推进 1.15 秒地图收尾。

致命收势不走 0.65 秒提前解锁分支，动作完成后保持最终姿势。落地完成后只计分一次，直接从收势切到胜利首帧，敌人保留最终倒地姿势。祢豆子的旧觉醒图集胜利片段实际仍是普通形态，因此通过觉醒配置 `victory_source_clip = "idle"` 复用现有觉醒站姿帧，保留胜利片段时序，呈现平稳站定的胜利收势；头像同步保留觉醒形态。模型的觉醒计时照常清理，展示形态在下一回合或退出时清除。非致命必杀维持原交接行为，练习模式不增加 KO 或回合结算。

暂停、帮助和设置冻结定格时钟与收尾；静音和音量继续即时生效。解码失败且没有缓存帧时，直接返回地图，在地图上显示一次 KO 后完成收尾和胜利衔接，不使用空白纹理、不重复播报。

## 复现与验证

`python tools/prepare_cinematics.py --source <完整原视频.mp4>` 重新生成7个OGV、7个裁短MP4和8项招式映射。

`tests/cinematic_tests.gd` 覆盖四角色/奥义及MAX/双方槽位/左右方向、伤害和气量一次结算、计时冻结、防御/挥空/关闭设置、KO延后及落地不重复、重置和配置迁移。

`tests/cinematic_handoff_tests.gd` 无画面验证完整 HUD 恢复、暂停、提前解锁操作、敌人倒地保持、跳跃不中断以及交接时贴图持续存在；不播放或录制视频。

`tests/cinematic_ko_tests.gd` 覆盖四角色、两类必杀、双方槽位、左右方向、首击和后续段致命、觉醒映射与数值不变、全程输入锁定、暂停、异常回退、退出重开和下一回合状态清理。

`tools/capture_cinematic_ko.gd` 使用真实 Theora 解码和 GPU 渲染验证定格纹理、阶段时长、地图交接及觉醒胜利帧；`--matrix` 检查 32 项角色/招式/槽位/朝向组合，`--fps=30/60/144` 配合引擎 `--fixed-fps` 检查时序。默认录制觉醒祢豆子普通奥义，可配合 `--write-movie` 导出带声音的完整演出。输出位于 `artifacts/cinematics-ko/<fps>/`。

`tools/capture_cinematics.gd` 在真实渲染窗口检查8项映射、Theora播放、暂停/音量/静音、设置菜单和当前场景收尾；截图与日志保存在 `artifacts/cinematics/`。逐帧快进的原有UI测试显式关闭视频，实际视频时钟由专用实机检查覆盖。

首次接入验证结果：完整回归通过（30 / 60 / 144 FPS 状态一致）；308 项演出战斗检查、96 项实机播放/音画同步/暂停/收尾检查通过；7 个1080p60视频与独立音轨全部解码无错误、帧数精确匹配。实机示例：output/ultimate-video-review/zenitsu-integrated-preview.mp4。
