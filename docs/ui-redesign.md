# 「大正墨金」前端 UI 重设计

本次重做全部前端表现：菜单、战斗 HUD、回合大字、超杀切入，以及攻击与技能特效。战斗规则与数值、角色头像与立绘、动作动画、必杀视频和地图背景均未改动；`combat.gd`、`round_flow.gd`、招式与角色资源保持原样，30／60／144 FPS 战斗状态哈希仍然一致。

风格对标《鬼灭之刃 火之神血风谭》：墨迹笔触、金箔描边、羽织纹样、书法大字与朱红印章。所有美术均为程序化绘制（GDScript 绘制 + Shader + 内联 SVG），不依赖生图服务，4K 下保持锐利。

## 设计系统

| 项目 | 规格 |
| --- | --- |
| 色板 | 墨 `#06080D`～`#1E2536`，和纸 `#F3EAD3`，金箔 `#FFE9B0 / #E0B460 / #9A7332`，朱漆 `#D02B3F / #7C1222`；P1 浅葱 `#4FD2F0`、P2 朱樱 `#FF5D7A`，菜单、HUD 与脚下标记统一 |
| 字体 | 书法大字：马善政楷书；标题与菜单项：思源宋体 Black；正文：思源黑体 Medium；数字与英文副标：Oswald Bold。均为 SIL OFL 1.1 |
| 母题 | 墨带笔触、双线金框与角花、朱红印章、羽织纹样（炭治郎市松、善逸鳞纹、祢豆子麻叶、猗窝座罗针）、元素纹章取元素名首字（水／雷／血／破） |
| 动效 | 入场 ease-out 0.2 秒、错峰 25 ms 且封顶；焦点时朱红墨带擦入；切屏墨刷转场 0.3 秒；入场只偏移绘制，不移动控件，点击区域即时有效 |

代码位置：

- `scripts/ui/kit.gd`：色板、缓动和无状态绘制原语（斜切、刀形条、金框、印章、键帽、手柄键、方向箭头、鍔形徽章、纹样、二维柔和渐变）。
- `scripts/ui/ui_assets.gd`：由视觉目录懒加载；内联 SVG 以 3 倍栅格化（拨动开关、菱形滑块、下拉箭头等），生成原生控件 Theme。
- `scripts/ui/shaders/`：`brush_band`（干笔墨带）、`gradient_text`（金属渐变字）、`gauge_fill`（血条流光）、`meter_flow`（气槽能量）、`ink_wash`（菜单墨烟）、`speed_lines`（集中线）、`pause_backdrop`（暂停去饱和模糊）、`stacked_alpha`（选人展示视频的叠层 alpha 合成）。时间均由脚本传入，暂停即冻结。
- 组件：`brush_stroke.gd`、`gradient_text.gd`、`prompt_bar.gd`／`prompt_label.gd`（按键提示渲染为键帽与手柄字形）、`screen_backdrop.gd`、`screen_header.gd`、`screen_wipe.gd`、`fighter_showcase.gd`／`select_video.gd`（选人侧栏与展示视频）、`roster_card.gd`（选人宫格）、`stage_preview.gd`、`command_glyphs.gd`（`236 + A/C` 渲染为 ↓↘→ 与按键字形）。

## 界面

- **标题**：海报全屏，左下二维墨晕保证可读性，余烬微粒上浮；五项菜单带印章序号与英文副标，焦点项说明显示在底部提示条。提示条的键帽／手柄按键随标题页最近使用的设备即时切换。
- **选人**：中央金框格板内为 4 列宫格（暂定 4×4＝16 格）：现有角色依次排列，其余为「敬请期待」空位，最后一格固定为「随机」；超过 15 名角色时自动加行并滚动。左右两侧为 P1／P2 的抠像展示视频（P2 镜像，贴屏幕外缘，内侧与底部柔化，见 `docs/select-videos.md`），背景墨烟随角色色调变化；书法角色名、元素印章、定位与觉醒名；就绪时盖「就绪」朱印。光标横纵循环，空位可停留但不能确认；随机格确认后先播约 0.7 秒头像轮盘再落定（转动期间宫格光标停在随机格、背景保持中性色）。双方都锁定后停留约 1.3 秒（随机则从轮盘落定算起）：格板压暗，朱红笔刷带上砸下金色「VS」，下方返回／确认按钮和提示同时变暗禁用；确认键不能跳过，返回键可撤销刚才的锁定；随后进入选图。没有展示视频的角色回退为立绘。顶部步骤「角色 → 场景 → 开战」。
- **选图**：左侧大预览（缓推、交叉淡入、书法地图名与对阵头像），右侧竖排地图卡（缩略图与地图名，不再附介绍文字）。
- **暂停**：战斗画面去饱和模糊，左侧墨色侧栏，右侧 P1「招式速查」。
- **结算**：胜者色墨烟与斜劈墨带，金渐变书法「胜」与金箔粒子。
- **帮助**：页签式；键帽对照表、印章编号规则、指令字形招式表、普通技属性标签。
- **练习设置、游戏设置**：漆面卡片与主题化开关、滑块、下拉框；键位以键帽按钮显示并标注功能名。
- 菜单焦点移动与返回新增程序化提示音 `ui_move`、`ui_back`。

## 战斗 HUD

| 区域 | 设计 |
| --- | --- |
| 头像 | 斜切金框，按多边形裁剪战斗头像（觉醒自动切换），P1／P2／CPU／木桩标签；元素纹章与呼吸法名称只在下方气槽显示，名字旁不再重复 |
| 血条 | 刀形金框，金→琥珀→危急朱红脉动，周期流光；受击先白闪再转深朱尾迹，并立即开始缓降 |
| 计时 | 中央鍔形徽章，最后 10 秒转朱红；下方「第壹回合」，练习为「修炼模式 ∞」 |
| 胜场 | 血条内端两枚菱形，获胜时点亮并弹出 |
| 气槽 | 元素纹章 + 三段能量流（`meter_flow`），满格脉动，MAX 金色辉光；保留扣气、气量不足和觉醒提示 |
| 觉醒 | 血条下觉醒色飘带（纹章、名称、倒计时、递减线），发动时「觉 醒」墨带横扫 |
| 连击 | 墨带底板 + Oswald 斜体金渐变数字，10／20 段升级配色，结束后淡出 0.45 秒 |
| 练习 | 左侧输入记录（帧数、方向箭头、ABCD 字形）、训练状态条、搓招提示卡 |

HUD 动画只按 `delta * playback_speed` 推进：暂停（`frozen`）与 KO 冻结时完全静止；命中停顿和超杀冻结（`held`，由 `world_view` 每帧设置）时，白闪、残血条、连击、招式名和流光与舞台、特效一起定格，扣气、气量不足与「觉 醒」横扫照常播放，因为它们和超杀切入一样，本来就安排在冻结期间演出。必杀视频期间不定格。

## 回合大字与超杀切入

| 战斗事件 | 显示 |
| --- | --- |
| `ROUND n` | 第壹回合 / ROUND 1 |
| `READY` | 全集中 / READY |
| `GO!` | 开战 / FIGHT（集中线爆发） |
| `K.O.` | K.O. / 胜负已分（朱红斜劈） |
| `DOUBLE K.O.` | DOUBLE K.O. / 两败俱伤 |
| `TIME UP` | 时间到 / TIME UP |
| `DRAW` | 平局 / DRAW |
| `Pn WINS` | 胜 / Pn WINS · 角色名 |

横幅仍只读取战斗模型给出的 cue，动画完全由 `age` 驱动，演示场景与必杀 KO 冻结画面共用。超杀时背景改为径向暗角并叠加元素色集中线，标题行有切入墨带，MAX 头像为金框斜切；无插画标题的招式使用书法金字。

## 攻击与技能特效

- 普攻刀光按角色强调色（觉醒时用觉醒色）绘制三层月牙与刀尖辉光，并附角色特征：水珠、细电弧、粉焰、罗针环。
- 命中：光核、8～12 道星芒、强化冲击环与火花；重击和技能更大；超杀／MAX 命中时全屏轻微白闪（≤12% 透明度，约 0.09 秒）。
- 防御：朝向攻击方的蓝色六边形护盾与偏折火花；投技落地尘环；拼招为金白爆闪；拆投保持单一提示。
- 元素技在原贴图本体上叠加水滴、余烬、电火花、血樱与罗针环；飞道具留下水沫尾迹；超杀蓄力有旋转地面法阵。
- 新粒子寿命均短于 0.35 秒，有数量上限，随命中停顿和暂停冻结。

## 字体与重建

字体子集化与 OFL 许可：

```powershell
# 首次或更换字体源时下载原始字体（输出到 output/font-sources，已被 Git 忽略）
.\.venv\Scripts\python.exe -X utf8 tools/subset_fonts.py --fetch
# 修改任何界面文字后都要重新子集化，再导入
.\.venv\Scripts\python.exe -X utf8 tools/subset_fonts.py
& $env:GODOT --headless --path . --editor --import --quit
```

`art/fonts/fonts.json` 记录各字体来源路径与 SHA-256；`tests/ui_redesign_tests.gd` 会检查所有界面汉字均已被打包字体覆盖。
