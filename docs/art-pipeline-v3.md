# 角色美术管线 v3（一致性重绘）

总体方案见 [moveset-animation-plan.md](moveset-animation-plan.md) 第三节。炭治郎是第一个使用 v3 管线的角色；其他角色动工前，先用同一套质检指标给现有图集打分，再决定重绘深度。

## 为什么要重做

旧版炭治郎画面不一致有四个原因：

- 每个动作片段都是一次独立的生图调用；
- CPA 忽略请求尺寸，导致各片段的重采样倍率在 0.42–1.24 之间，线宽也跟着变；
- 比例靠手调；
- 没有锁定配色。

另外，待机只是一张静止图。

## 流程

| 步骤 | 工具 | 说明 |
|---|---|---|
| 定稿 | `tools/art_v3/canon.py` | 生成 v3 设定图和待机姿势候选，由用户选定（检查点 ①） |
| 待机 | `tools/art_v3/idle_warp.py` + `spec/<id>-idle-rig.json` | 对选定的关键姿势做 MLS 网格形变：12 帧、10fps 循环，脚底固定（检查点 ②） |
| 开场 | `tools/art_v3/intro_warp.py` + `spec/<id>-intro-rig.json` | 由辅助片段的关键画（编辑图，按下半身与待机第 0 帧配准）和待机关键姿势的形变拼成 18 帧：关键画在缩放前按全分辨率形变（呼吸、衣摆），形变帧里刀以握柄为轴整体转动；18 张互不相同，末帧就是待机第 0 帧（逐像素一致）。`process.py --clips round_intro` 调用它 |
| 任务 | `tools/art_v3/prepare.py` + `poses/<id>.json` | 根据逐帧姿势脚本生成提示词和任务清单（`output/imagegen/<id>-v3/jobs.json`） |
| 生成 | `tools/art_v3/run.py` | 同一片段的各批按顺序生成（后一批引用前一批），不同片段并行；底层调用 `tools/run_roster_art_job.ps1`，每次请求都有记录，从不自动重试 |
| 处理 | `tools/art_v3/process.py` | 抠像 → 调色板锁定 → 分离各帧 → 头部标尺 / 重叠帧校准比例 → 锚点 → `imports/<clip>/frame-NN.png` 与质检记录 |
| 预览 | `tools/art_v3/preview.py` | 临时装进游戏图集，用于实机审阅（`--restore` 撤回） |
| 打包 | `tools/art_v3/pack.py` | 输出 `atlas.json`、`round-atlas.json`、`awakening/atlas.json`（斑纹由 `awaken.py` 烘焙）和 `pack.json` |
| 刀刃轨迹 | `tools/build_blade_tracks.py <id>` | 每次打包后都要重建，特效跟随画出来的刀 |
| 录像 | `tools/capture_moves.gd`、`tools/capture_idle_loop.gd` | 游戏内真实渲染，供人工验收 |

## 硬规则（来自试制）

1. **每张图一律 1536×1024，列一定画满**：
   - 高格每列 512×1024，每张 3 帧；宽格每列 768×1024，每张 2 帧。
   - 不满一张时，用前面的帧补满（重叠帧），因为列一变宽，模型就会把人物画大、比例也会走样。
   - 512×512 的小格会画出大头短腿的比例，姿势也会偏离定稿。
2. **按头部标尺定比例**：标尺取“头发 + 脸部皮肤”面积的平方根，人物旋转时不变（待机 12 帧误差约 ±1%）。
   - 三帧的图取中位数，两帧的图取露脸最完整的那一帧（遮挡只会让测量值偏小）。
   - 有重叠帧时，优先用重叠帧的身高直接校准。
   - 空翻、倒地等旋转帧的头部经常被遮挡或倒置。这类图的测量值偏离片段中位数超过 12% 时，改用中位数（优先取直立帧所在图的中位数）。
   - 直立帧不做这种回退：站直的姿势模型确实会画得更大，例如回合开场第一张。
3. **调色板锁定**：只锁羽织绿、制服和皮肤三类，而且只在色差 ΔE 大于 2 时才校正。发色分类会误抓裤装高光，只用于质检。
4. **提示词必须写明标尺**：护手到刀尖约 350px，待机身高 840px，发顶到下巴 160px。不写的话，刀和身高都会漂移。
5. **锚点**：
   - 普通帧：根点 x 取制服重心，脚底贴地；
   - 空翻、受投等旋转帧：制服重心放在锚点上方 165px（`anchor: pelvis`）；
   - 躺地帧（`ground_mode: lying`）：身体本身的最低处贴地。先用比刀身更宽的开运算去掉刀、手指等细长部分，否则掉落的刀会把身体顶起来，看起来悬空。
6. **平躺的帧不能用重叠帧校准**：重叠帧按“发顶到脚底”的高度校准，而躺着的身体这个高度取决于腿怎么摆。受击倒地第 4 帧（躺平）所在的图，用前一帧（半躺、抬腿）做重叠帧校准，结果缩到 66%。现在重叠帧是躺地帧时不参与校准，这张图只按自己画的帧量头部标尺。
7. **平躺的身体放不进一列**：768px 宽的列放不下 880px 长的身体，模型会把整个人画小。这时头部标尺是对的，不能当成异常值退回中位数。规则：旋转帧所在的图，只要有一帧身体舒展（主轴长度 ≥ 次轴的 1.8 倍），就采用头部标尺；但身体长度不能超过待机的 1.05 倍，超过时按这个上限缩放。平躺的提示词要写“从侧面、贴地平视，不要俯视”，否则会画成斜 45 度。
8. **投技受害者朝向**：游戏用投者的朝向画受害者，所以受害者的图必须面朝投者（朝左）。生成时仍一律朝右，姿势脚本标记 `"mirror": true`，由 `pack.py` 在烘焙觉醒斑纹之后，以脚底锚点为轴镜像。
9. **按身高对齐**（`match_height`）：同一片段中静止姿势的后一张图，可以对齐到前面已登记的帧（`"parts": [5]` 只作用于第 6 张），例如胜利动作最后一张。不要用它对齐姿势不同的两个片段：蹲防举刀时头压得更低，按“发顶到脚底”对齐反而把人放大了。
10. **额外参考图**：姿势脚本可以写 `"reference": {"image": …, "role": …}`，作为下一张输入图交给模型。
11. **只改局部的动作用编辑模式**（`"edit": {"image": …}` + `"register": {"clip": …, "frame": …}`）：蹲防就是蹲姿换了手臂和刀。`prepare.py` 把蹲姿原图按列排进输入图 1，提示词要求身体完全不动、只改手臂和刀；模型仍会把人物放大约 14%。`process.py` 再把每帧按下半身（腿、脚、刀鞘）与游戏里的蹲姿帧做模板匹配，搜索缩放和位移，两者的身体完全重合。
12. **小幅、连贯的动作用形变，不要逐帧生图**：开场逐帧生成时，每张图都会重新诠释动作（刀反复举放、步幅和衣摆变化）。从定稿关键帧形变出来的帧，造型、比例和线条完全不变。形变片段都先补到同样的边距（`WARP_PAD`）再缩放，所以相同的图得到完全相同的像素。
13. **觉醒版**：从普通版逐帧派生。在面部前半区找到额头疤痕，沿皮肤扩成斑纹并加深颜色。除斑纹外像素完全相同，背对或转头的帧不画斑纹。
14. **辅助片段**（姿势脚本 `"helper": true`）：只给别的片段提供关键画，`pack.py` 不打包；`process.py` 额外保存每张原分辨率的画（`drawing-NN.png`）和精确的配准比例，供拼装时先形变再缩放。编辑模式可以写 `"left"`（人物离列左边的距离，给向前伸的刀留位置）、`"keep"`、`"change"` 和 `"rule"`（覆盖默认的“保持不变 / 只改手臂和刀 / 不许重画身体”三句，例如允许改眼睛，或在腿脚不动的前提下鞠躬）。`"layout": "full"`（整张 1536 宽只有一列）只能用于编辑：编辑图会保持底图的大小，所以剑指对手这种刀伸得很远的姿势也不会被画大。
15. **拔刀这类机械动作，模型画不对中间帧**：两次要求“刀半出鞘、横在腹前、刀尖还在鞘里”，都画成了反握或连鞘横持。改为先编辑出拔刀完成的关键画，再以它为底图编辑出“刀平举 → 上扬 20°”两张，刀只朝一个方向扬起。也不要用网格形变把画好的刀转 40° 以上：护手会被拉长、刀柄会弯，护手边缘还会留下碎片。

## 质检（`tests/art_v3_tests.py`）

- 打包输出和每张原图的哈希都与记录一致；
- 每张图的重采样倍率在待机的 0.62–1.1 倍之间（站直姿势的图会被模型画得更大，例如回合开场为 0.66）；整张图都是躺地或旋转帧时上限放宽到 1.2；
- 锁定的三类材质 ΔE ≤ 4.5（旧版各片段之间是 8–15）；
- 任何帧都没有阻断级标记（头部大于同图参考、超出画布、直立帧身高偏离待机 ±5%）；
- 待机 12 帧循环首尾衔接、脚底不动；
- 觉醒版的片段、帧数和时间元数据与普通版一致，每帧只有斑纹区域（≤200 像素）不同。

旧的 `art_pipeline_tests.py` 和 `awakening_art_tests.py` 会按图集修订号（`<id>-v3`）自动切换到 v3 的检查。

## 试制记录（炭治郎）

用户对检查点 ③ 的反馈和处理结果：

- 行走第 6、7 帧、水面斩第 8 帧变矮：来自不满格的最后一张图，改为补帧重画并用重叠帧校准；
- 水面斩第 3、5 帧刀身变短：在提示词中加入刀长标尺后重画。

所有修正都以 `-r1` 任务记录，旧任务标记为 `superseded_by`。

用户对检查点 ④ 的反馈和处理结果（任务组 `review4-r1`，共 51 张）：

- 开场和胜利动作重复（开场里收刀拔刀出现了三次）：改成单向推进，只拔刀或收刀一次，后段保持不动；
- 投技动作怪异：前投改为抓领扫腿砸地，背投改为扭身把对手甩到身后，全程朝右，不转身；
- 受投和战败倒地时变小、悬空、斜 45 度：原因见硬规则 5–8；
- 5D 腿短、来回转身：改为一次侧踢，强调腿长；
- 蹲防：与蹲姿相同，刀横举过头顶；
- 待机两脚不在同一水平线：前脚比后脚高 39px。待机 rig 新增 `offsets`，每帧把前脚、脚踝、膝盖下移到后脚的地平线。

第二轮反馈（任务组 `review5`，2 张编辑图）：

- 开场仍然来回举刀、不连贯：放弃逐帧生图，改用 `intro_warp.py` 从待机关键帧形变——低头、压低重心、刀放低 22°，一次缓慢呼吸后抬起进入架势，末帧即待机第 0 帧；原来的 9 张开场任务标记为 `superseded_by: intro_warp`；
- 蹲防比蹲下明显变大，而且身体造型不同：改为编辑蹲姿原图，双手换到身体另一侧（后上方），反手持刀横在头前上方，再按下半身配准（硬规则 11）。

第三轮反馈（任务组 `review6`、`review6-r2`，共 5 张编辑图；`review6-r1` 的 1 张弃用）：

- 开场要彻底重做：改为一个单向推进的动作——收刀闭目、全集中呼吸（关键画按全分辨率形变，吸气时肩和头上提）→ 睁眼 → 一闪拔刀（刀平举 → 上扬 → 单手举到架势角度）→ 左手合握、呼气下沉，落到待机第 0 帧。全部关键画都是待机第 0 帧的编辑图，按下半身配准，步幅和身体从头到尾不变。半出鞘的中间帧模型两次都画错（硬规则 15），改用拔刀完成那张画的编辑图做中间帧。开场另有水之呼吸特效（第四轮已删除）；
- 蹲防：刀改为水平横在额前，一手握柄在脑后一侧、另一手掌心托住刀背，不再举过头顶；
- 被下段重攻击击倒后躺地变小（第 4 帧只有正常的 66%）：原因见硬规则 6，修正后头部与待机一致，躺姿长度和战败躺地相同。

第四轮反馈（任务组 `review7`，共 4 张编辑图）：

- 开场再重做一版，去掉水花特效，动作也换掉，参考拳皇、街霸的开场：改为“一礼 → 拔刀 → 剑指对手 → 入架势”。收刀立于架势中，向对手鞠躬（拳皇金家藩、坂崎琢磨式的礼），起身握柄，拔刀平举，随即把刀笔直指向对手眼睛并停住约 0.45 秒（宣言式定格），再双手合握入架势，呼气微沉后落到待机第 0 帧。关键画来自三个辅助片段：`intro_bow`（备战、半礼、全礼、起身握柄、握柄、双手入架势，待机第 0 帧的编辑图）、`intro_cut`（上一版的拔刀平举）和 `intro_point`（剑指，在拔刀平举那张上编辑，单列整宽）。鞠躬那几张站得稍直，前脚比架势前移约 8px，后脚全程不动；
- 上一版开场特效 `vfx/tanjiro/intro.gd` 已删除，开场不再有任何特效。
