鬼灭之刃：宿命对决 — Windows x64

无需安装 Godot、Python 或其他开发工具。
1. 将整个 ZIP 解压到一个文件夹。
2. 双击 DemonSlayer.exe。DemonSlayer.pck 必须留在同一文件夹。
3. 选择电脑对战、本地双人或自由练习；支持键盘和手柄。

P1：WASD 移动，U / I / J / K = 轻攻击 / 轻体术 / 重攻击 / 重体术。
P2：方向键移动，小键盘 5 / 6 / 2 / 3 = 四个攻击键。
菜单：P1 的 U 确认、I 返回；P2 的小键盘 5 确认、6 返回。
手柄：方向键或左摇杆移动；菜单 A 确认、B 返回。
Esc 暂停；F2 静音；练习中 F3 打开练习设置、Backspace 重置。
可在「游戏设置」中改键、调整声音和分配手柄。

B+C 觉醒：P1 默认 I+J，P2 小键盘 6+2，手柄 A+Y，消耗2格气。
地面普通发动持续10秒；普通技命中后快速发动持续6秒，可再接一轮普通技。
四人各有属性强化；祢豆子持续鬼化，命中可少量回血。觉醒期间停止回气。
练习设置提供2格气及觉醒时间无限，仍通过 B+C 发动。

当前有炭治郎、善逸、祢豆子、猗窝座 4 名可玩角色及 4 张地图。
海报中的其他人物暂非可玩角色。双人模式为同一台电脑本地对战。
设置保存在 %APPDATA%\Godot\app_userdata\鬼灭之刃：宿命对决\settings.cfg。
Windows 10/11 x64，显卡需支持 OpenGL 3.3。此版本未进行代码签名。
